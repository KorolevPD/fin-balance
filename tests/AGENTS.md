# Правила для тестов

Перед изменением тестов прочитайте корневой `AGENTS.md`, стратегию тестирования в `PLAN.md`, текущую запись в `TASKS.md` и собственный timestamp-файл.

## Требования

- Названия тестов пишите по-русски.
- Каждый тест должен проверять один наблюдаемый результат.
- Сначала воспроизведите ошибку падающим тестом, затем исправляйте код.
- Не ослабляйте существующий тест только ради зелёного результата.
- Не используйте внешние зависимости без одобрения.

## Проверка

```bash
npm test
```

В timestamp-файле запишите:

- какие тесты были запущены;
- сколько тестов прошло и не прошло;
- какой ручной сценарий дополнительно проверен;
- остались ли непроверенные крайние случаи.

Перед сложной тестовой задачей прочитайте `docs/rules/testing.md`.
