# Правила для исходного кода

Перед изменением файлов этого каталога прочитайте корневой `AGENTS.md`, `PLAN.md`, текущую запись в `TASKS.md` и собственный timestamp-файл.

## Язык

- Пользовательские тексты пишите по-русски, если `PRODUCT.md` не требует другого.
- Идентификаторы JavaScript оставляйте понятными и преимущественно английскими.
- Не добавляйте очевидные комментарии; сложные решения объясняйте кратко на русском.

## Ограничения

- Используйте браузерные API и стандартный JavaScript.
- Не добавляйте зависимости без явного одобрения.
- Не создавайте backend без требования в `PRODUCT.md`.
- Изменяйте только файлы, разрешённые текущей задачей.

## Проверка

После изменений выполните:

```bash
npm run check
```

Если меняется интерфейс, дополнительно проведите ручную проверку в браузере и запишите её результат в timestamp-файл.

## Дополнительные правила

- Для интерфейсной задачи прочитайте `docs/rules/frontend.md`.
- Для вопроса безопасности прочитайте `docs/rules/security.md`.
- Не читайте оба документа заранее, если они не относятся к задаче.
