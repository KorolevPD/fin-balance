# Документы проекта

- `OPENCODE_FREE_MODELS.md` — текущие бесплатные модели OpenCode Zen и правила экономии.
- `MCP_LSP_CODEGRAPH.md` — назначение MCP, LSP и CodeGraph.
- `SKILLS_SECURITY.md` — безопасность сторонних skills и исполняемых scripts.
- `rules/` — подробные инструкции, загружаемые только по необходимости.
- `agent/tasks/` — timestamp-файлы выполнения задач и шаблон передачи состояния.

Не копируйте содержимое всех документов в корневой `AGENTS.md`. Держите общий файл коротким, а подробности загружайте по задаче.
