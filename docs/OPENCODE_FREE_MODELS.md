# Бесплатные модели OpenCode Zen

Актуально на **03.09.2026**. Официальный список может измениться в любой момент; перед работой выполните `/connect` → `OpenCode Zen` → `/models`.

## Текущий список

- `Muse Spark 1.3 Contributor Free`
- `Muse Spark 1.2 Contributor Free`
- `MiMo-V2.5 Free`
- `Nemotron 3 Ultra Free`
- `Nemotron 3.5 Lightning Free`
- `Ling 3.0 Flash Fin Free`
- `Big Pickle`

## Практический выбор для курса

1. **Muse Spark 1.3 Contributor Free** — основной старт для кодирования и agentic-задач.
2. **MiMo-V2.5 Free** — универсальный резерв.
3. **Nemotron 3.5 Lightning Free** — быстрые небольшие шаги и проверки.
4. **Nemotron 3 Ultra Free** — сложный анализ и координация.
5. Остальные модели сначала проверяйте на маленькой задаче.

Для независимого review полезно выбрать модель другого производителя, чем модель-исполнитель, например Muse → MiMo или Nemotron. Это не отменяет проверку через Git diff и тесты.

## Ограничения и данные

- Все бесплатные модели указаны OpenCode как доступные ограниченное время.
- Список, скорость и ограничения могут измениться.
- Некоторые free-endpoint допускают использование запросов и ответов для улучшения моделей.
- Не отправляйте API-ключи, `.env`, персональные данные и конфиденциальный код.
- Один запрос OpenCode может вызвать несколько обращений к модели; работайте маленькими шагами.
