# MCP, LSP и CodeGraph

## MCP

MCP подключает к агенту внешние инструменты и источники данных. Каждый сервер добавляет описания инструментов в контекст, поэтому не включайте всё одновременно.

- `Context7` — документация библиотек и API.
- `grep.app` — примеры использования в открытом коде.
- `CodeGraphContext` — локальный граф файлов, символов, импортов, вызовов и зависимостей.

## CodeGraphContext

CodeGraph полезен, когда простого поиска по строкам недостаточно: нужно проследить цепочку вызовов, понять границы модулей или оценить область влияния изменения.

Пример установки:

```bash
pip install codegraphcontext
cgc index .
cgc mcp setup
```

В `opencode.jsonc` приведён отключённый пример запуска MCP:

```json
"codegraph": {
  "type": "local",
  "command": ["codegraphcontext", "mcp", "start"],
  "enabled": false
}
```

Перед включением проверьте исходный код, зависимости и объём создаваемого индекса. Не индексируйте секреты и каталоги, которые не относятся к проекту.

## LSP

LSP помогает агенту находить определения и ссылки, видеть типы и диагностику. Он понимает структуру локального кода, но не заменяет тесты бизнес-логики.

## Практическое правило

1. Сначала используйте встроенный поиск и LSP.
2. Подключайте Context7, когда нужна документация версии.
3. Подключайте grep.app, когда нужен внешний пример.
4. Подключайте CodeGraph для сложных связей по всему репозиторию.
5. После использования отключайте ненужные MCP, чтобы не расходовать контекст.
