# Память агента

- `PLAN.md` — стабильный план реализации и тестирования.
- `TASKS.md` — детали реализации, текущий статус и ссылка на последний файл выполнения.
- `docs/agent/tasks/T-XXX/*.md` — отдельные timestamp-файлы каждой попытки выполнения задачи.

После перезапуска агент читает `AGENTS.md`, `PRODUCT.md`, `PLAN.md`, `TASKS.md`, последний файл текущей задачи и состояние Git. История чата полезна, но не является источником истины.
