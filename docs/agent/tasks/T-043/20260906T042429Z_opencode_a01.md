## Решение по удалению (подтверждено пользователем)

Удаление файла удаляет и относящиеся к нему операции (транзакции) и их
исправления (UserCorrection). API:

`DELETE /families/{family_id}/transactions` с query-параметром
`source_file=<имя>`:
- право на удаление — только у т commentaryского пользователя, загрузившего файл
  (по user_id, как в сводке uploaded_files);
- 404, если выписки нет для этого пользователя;
- удаляет UserCorrection по операциям, затем Transaction с этим source_file.

## Реализация

Backend `backend/app/routers/transactions.py`:

```python
@router.delete("/{family_id}/transactions", ...)
def delete_transactions_by_file(
    family_id: UUID,
    source_file: str = Query(..., min_length=1, max_length=255),
    db: Session = Depends(get_db),
    current_user: User = Depends(get_current_user),
):
    _require_membership(db, family_id, current_user.id)
    transactions = db.query(Transaction).filter(
        Transaction.family_id == family_id,
        Transaction.user_id == current_user.id,
        Transaction.source_file == source_file,
    ).all()
    if not transactions:
        raise HTTPException(status.HTTP_404_NOT_FOUND, "Выписка не найдена")
    transaction_ids = [t.id for t in transactions]
    db.query(UserCorrection).filter(
        UserCorrection.transaction_id.in_(transaction_ids)
    ).delete(synchronize_session=False)
    db.query(Transaction).filter(
        Transaction.id.in_(transaction_ids)
    ).delete(synchronize_session=False)
    db.commit()
    return {"deleted": len(transaction_ids), "remaining": <count>}
```

Импортирован `Query` из fastapi; `UserCorrection` уже импортировался.

Тесты (tests/test_transaction_router.py, класс TestDeleteTransactionsByFile):
1. удаление выписки очищает её операции (deleted=2, remaining=0, GET пуст);
2. сводка пересчитывается после удаления (total_amount=0, uploaded_files=[]);
3. удаление несуществующей выписки → 404;
4. нельзя удалить файл другого пользователя → 404, операции владельца на месте;
5. удаление требует авторизации → 401.

- Удаление выписки с 1000+ операциями (bulk .in_) — допускается, тестовый
