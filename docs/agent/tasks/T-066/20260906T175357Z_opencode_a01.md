# T-066: Зелёный цвет переключателя «В семье / Личные» на дашборде

Дата: 2026-09-06T17:53:57Z
Владелец: opencode
Попытка: a01

## Цель

На переключателе общей суммы расходов («В семье» / «Личные») заменить
фиолетово-синий цвет активного состояния на зелёный — такой же, как на
кнопках.

## Анализ

Переключатель реализован в T-062 и находится на дашборде. Стили в
`frontend/src/styles.css`:

- `.scope-toggle` (строки 664-670) — контейнер переключателя;
- `.scope-toggle-btn` (строки 672-681) — кнопка «В семье» / «Личные», по
  умолчанию прозрачный фон, тёмный текст;
- `.scope-toggle-btn.active` (строки 691-694) — активная кнопка с
  фиолетово-синим фоном `#5b5bea` и белым текстом.

Цвет кнопок в проекте — зелёный `#24a647` (`.btn`, стилизуемые `button`),
при наведении `#1a8a39` (`.btn:hover`).

Заменяем цвет активной кнопки переключателя с `#5b5bea` на зелёный
`#24a647` — в точности как на кнопках, а при наведении на активную
кнопку — на `#1a8a39` (как `.btn:hover`).

## Изменения

1. `frontend/src/styles.css`, правило `.scope-toggle-btn.active`:
   - `background: #5b5bea` → `background: #24a647`;
   - `color: white` оставлен без изменений.
2. Добавлен hover для активной кнопки, согласованный с `.btn:hover`:
   - `.scope-toggle-btn.active:hover { background: #1a8a39; }`.

## Проверка

- `npm run check` — `Compiled successfully`.
- Активная кнопка переключателя «В семье / Личные» на дашборде теперь
  зелёная `#24a647` — тот же цвет, что у кнопок.
