## Цель выполнения

1. «Общая сумма расходов» и раздел «Члены семьи» — убрать знак минуса перед суммой.
2. «Банковские выписки» — заменить текстовую кнопку «Удалить» на иконку-крестик, расположить по правому краю ячейки.
3. «Операции» — перенести ссылку «Все операции» из шапки вниз блока, отцентровать, убрать стрелку «→».

## Диагностика (до изменений)

- `formatAmount(value, type)` в Dashboard.js (строка 86) по умолчанию ставит `−` для расходов.
  - Строка 328: `formatAmount(summary.total_amount)` — показывает «− … ₽».
  - Строка 376: `formatAmount(member.total_expenses)` — показывает «− … ₽».
- Кнопка «Удалить» в таблице выписок: строка 527, `td.files-remove-cell` (со стилем `text-align: center` от T-058).
- Ссылка «Все операции →»: строка 747, в `div.card-header-actions` внутри шапки блока «Операции».

## Решение

### 1. Убрать знак минуса (Общая сумма расходов + Члены семьи)

Добавить в Dashboard.js функцию `formatAmountPlain(value)`:
```js
function formatAmountPlain(value) {
  return `${Math.abs(Number(value || 0)).toLocaleString('ru-RU', { minimumFractionDigits: 2, maximumFractionDigits: 2 })} ₽`;
}
```

Заменить на ней:
- строку 328: `formatAmount(summary.total_amount)` → `formatAmountPlain(summary.total_amount)`
- строку 376: `formatAmount(member.total_expenses)` → `formatAmountPlain(member.total_expenses)`

Остальные вызовы `formatAmount` (категории, графики, топ-получатели, список операций) не трогаем.

### 2. Кнопка «Удалить» → иконка по правому краю

Заменить в Dashboard.js (строка 526–534) текстовую кнопку на inline SVG иконку (крестик ✕):
```jsx
<button
  type="button"
  className="icon-btn icon-btn-danger"
  aria-label={`Удалить выписку ${file.filename}`}
  title="Удалить"
  onClick={() => handleDeleteFile(file.filename)}
>
  <svg viewBox="0 0 24 24" width="18" height="18" fill="none"
       stroke="currentColor" strokeWidth="2" strokeLinecap="round"
       strokeLinejoin="round">
    <line x1="18" y1="6" x2="6" y2="18" />
    <line x1="6" y1="6" x2="18" y2="18" />
  </svg>
</button>
```

В styles.css:
- `.files-remove-cell` → `text-align: right; width: 48px;`
- Добавить:
```css
.icon-btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 32px;
  height: 32px;
  padding: 0;
  background: transparent;
  border: 1px solid transparent;
  border-radius: 8px;
  color: #dc2626;
  cursor: pointer;
  line-height: 1;
}

.icon-btn:hover {
  background: #fee2e2;
  border-color: #dc2626;
}
```

### 3. Ссылка «Все операции» — вниз блока и отцентровать

В Dashboard.js:
- Убрать `<Link ...>Все операции →</Link>` из `div.card-header-actions` (строки 747–749).
- После таблицы операций (после `</div>` — конец `table-scroll`, до блока `{transactions.length > 0 && sortedTransactions.length === 0 && ...}`), добавить:
```jsx
{sortedTransactions.length > 0 && (
  <div className="card-footer-link">
    <Link to={`/family/${id}/operations`} className="card-header-link">
      Все операции
    </Link>
  </div>
)}
```

В styles.css добавить:
```css
.card-footer-link {
  display: flex;
  justify-content: center;
  margin-top: 16px;
}
```
