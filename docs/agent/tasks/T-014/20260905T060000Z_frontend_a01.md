## Контракт API (предложение для бэкенда)

- `GET /api/families/{family_id}/summary` →
  ```json
  {
    "total_amount": -12457.3,
    "by_category": [{"category": "Продукты", "amount": -4500.5, "count": 12}],
    "top_payees": [{"payee": "Пятёрочка", "amount": -3200.0, "count": 5}],
    "monthly": [{"month": "2026-08", "amount": -9000.0}]
  }
  ```
- `GET /api/families/{family_id}/transactions` →
  ```json
  [
    {"id": "…", "date": "2026-08-01T10:00:00Z", "amount": -250.5,
     "original_description": "…", "cleaned_description": "Пятёрочка",
     "category": "Продукты", "source_file": "x.csv", "user_email": "a@b.c"}
  ]
  ```

## Критерии приёмки (4)

1. Страница `/family/:id/dashboard` отображает общую сумму расходов семьи.
2. Разбивка по категориям: таблица (категория, кол-во, сумма, процент) + график.
3. Топ-5 получателей платежей.
4. Список операций: дата, название, категория, сумма.

## Что сделано
