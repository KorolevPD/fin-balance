**Предыдущая:**
- T-070 (мерджен в main): навигационные кнопки советов заменены на SVG-шевроны
  (`.advice-nav-btn`, `stroke=#BDBDBD`). Основной макет блока остался прежним.

## Цель

Изменить расположение и вид элементов блока «Совет от AI» на дашборде
(`frontend/src/pages/Dashboard.js`, секция с aria-label="AI-совет"). Функционал
не меняется — только раскладка и вид кнопки «Новый совет».

## Требования задачи

1. **Кнопка «Новый совет»** — переместить в правый верхний угол блока, на место
   счётчика советов, на уровне заголовка «Совет от AI». Соблюдать расстояние от
   края. Вместо прямоугольной кнопки с надписью — небольшая квадратная кнопка с
   равными сторонами, текст убрать, на кнопку поместить изображение
   `pale-button.png`, углы слегка скруглить.
2. **Счётчик советов** («Совет N из M») — перенести в правый нижний угол блока,
   на уровень ряду кнопок. Сам счётчик (текст/формат) не менять — только
   расположение.
3. **Кнопки переключения (шевроны)** — остаются слева снизу, расположить рядом
   друг с другом с небольшим расстоянием (правую придвинуть к левой).

## Найденные ограничения

- `pale-button.png` лежит в корне репозитория (1254×1254). По конвенции проекта
  статику фронтенда кладут в `frontend/public/` и ссылаются абсолютным путём
  (`/logo2.png`, `/avatar.jpg`) → скопировать в `frontend/public/pale-button.png`.
- Изображение просмотреть нельзя (модель не поддерживает ввод картинок) — на
  кнопке отображается картинка как есть через CSS-фон `no-repeat contain`.
- Блок рендерится в ветках: no-key / loading / error / currentAdvice / no-advice.
  Кнопка «Новый совет» существовала только в ветке currentAdvice → оставляем её
  в этой ветке, просто в шапке карточки (верхний правый угол).

## План

1. Скопировать `pale-button.png` → `frontend/public/pale-button.png`.
2. `Dashboard.js`:
   - в `.card-header` вместо счётчика (при `currentAdvice`) вывести кнопку
     `.advice-generate-btn` (пустая, без текста, `aria-label`/`title`).
   - счётчик (`.muted`) перенести в конец `.advice-controls` с классом
     `.advice-counter` (для прижатия вправо).
   - из `.advice-controls` убрать кнопку «Новый совет» (переехала в шапку);
     шевроны идут парами слева.
3. `styles.css`:
   - `.advice-generate-btn`: квадрат (равные стороны, ~32×32), без рамки/текста,
     фон `#fff url('/pale-button.png') center/contain no-repeat`, лёгкое
     скругление углов (`border-radius`), состояние disabled.
   - `.advice-controls`: уменьшить gap (шевроны ближе), `flex-wrap` сохранить.
   - `.advice-counter { margin-left: auto }` — счётчик в правом нижнем углу.
