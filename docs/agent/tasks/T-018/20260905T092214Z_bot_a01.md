## Выполненные действия

- Создана ветка `feature/T-018-bot-summary` от `origin/main` (a38f405).
- В `backend/app/routers/bot.py` добавлен `GET /api/bot/summary` (Query `telegram_id`):
  - 401, если telegram_id не привязан к веб-аккаунту;
  - 400, если пользователь не состоит ни в одной семье;
  - агрегаты через `get_family_summary` (из `app.services.analytics`), переиспользован существующий сервис без изменения transactions-роутера;
  - ответ `BotSummaryOut` (family_id, total_amount, by_category, top_payees, monthly).
- В `bot/bot.py` добавлен хэндлер `@dp.message(Command("summary"))`:
  - запрос к `/api/bot/summary?telegram_id=...`;
  - форматирование ответа: общая сумма расходов, топ категорий, топ получателей;
  - понятные сообщения для крайних случаев: не привязан (401), нет семьи (400), нет транзакций (пустая сводка), серверная ошибка (500).
- Добавлен `tests/test_bot_summary.py` (SQLite через `session_factory`, паттерн test_bot_upload.py):
  - привязанный пользователь с транзакциями получает корректную сводку;
  - непривязанный telegram_id → 401;
  - пользователь без семьи → 400;
  - пустая сводка (нет транзакций) → total=0, пустые списки.
- TASKS.md: статус T-018 → DONE (3/3).
