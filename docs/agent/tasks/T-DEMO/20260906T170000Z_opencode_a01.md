Дата: 2026-09-06T17:00:00Z
Владелец: opencode
Ветка: `feature/T-demo-upload-prompt`

## Цель

Если у пользователя нет загруженных выписок, то на странице дашборда вместо «Примерного дашборда» выводится страница загрузки файла с подписью вида «Чтобы начать работать с нашим сервисом, загрузите вашу банковскую выписку».

## Контекст

- `DemoDashboard.js` при переходе на `/dashboard` проверяет `/families/my` и summary каждой семьи.
- Если найдены операции — редирект на реальный дашборд `/family/{id}/dashboard`.
- Если операций нет — компонент сейчас отображает «Примерный дашборд» с демо-данными из `/demo/dashboard`.
- Требование: заменить этот случай на страницу загрузки файла.

## Изменения

- `frontend/src/pages/DemoDashboard.js`: полностью переписан. Убрано отображение «Примерного дашборда» с демо-данными (recharts, таблицы членов/категорий/выписок). Вместо этого при отсутствии загруженных выписок теперь выводится страница-приглашение: «Добро пожаловать! Чтобы начать работать с нашим сервисом, загрузите вашу банковскую выписку.» + кнопка «Загрузить выписку», открывающая `UploadModal`. Логика редиректа на реальный дашборд при наличии операций сохранена без изменений.
