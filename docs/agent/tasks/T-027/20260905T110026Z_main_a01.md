## Задача

Главная страница, доступная только не зарегистрированным / не вошедшим
в аккаунт пользователям.

- Фоновое изображение — будет прислано заказчиком позже (пока placeholder-градиент).
- По центру — белое текстовое окно, разделённое на 2 части:
  - справа — `logo1.png`;
  - слева — текст:
    - Заголовок «Понимай деньги проще» (крупный зелёный шрифт);
    - описание про импорт выписок, категоризацию и диаграммы;
    - строка про Сбер курсивом.
  - В нижней части окна — синяя кнопка с закруглёнными краями,
    белым жирным текстом «Зарегистрироваться/войти».
- Логика: если пользователь авторизован, `/` перенаправляет на `/upload`;
  если нет — показывается лендинг.
