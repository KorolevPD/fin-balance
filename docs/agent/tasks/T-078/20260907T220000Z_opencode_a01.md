## Задача пользователя

Кнопка генерации совета в блоке «Совет от AI» на дашборде не выглядит
кликабельной. Уточнение пользователя: добавить ей ТОНКУЮ СВЕТЛО-ЗЕЛЁНУЮ
окантовку (вместо серой).

## Реализация

- `frontend/src/styles.css`:
  - `.advice-generate-btn`: вместо `border: none` — тонкая светло-зелёная
    окантовка `1px solid <светло-зелёный>`, радиус скругления сохраняется
    (8px). Цвет окантовки подбирается в гамме основного зелёного проекта
    `#24a647` (светлый оттенок, например `#8fd8a4`).
  - hover-эффект и `:disabled` не меняются.

## Проверка

- Backend не затрагивается, python-тесты не нужны.
- Frontend: `npm run check` (react-scripts build), `CI=true npx react-scripts test`.
- Ручной сценарий (браузер): на дашборде при наличии совета кнопка
  «Новый совет» имеет тонкую светло-зелёную окантовку и выглядит кликабельной;
  наведение подсвечивает её (box-shadow).

## Итог попытки a01 (выполнена, 2026-09-07)

### Ручной сценарий (браузер, для проверки пользователем)

- Открыть дашборд, при наличии совета справа от заголовка «Совет от AI» кнопка
  «Новый совет» (картинка pale-button.png) теперь имеет тонкую светло-зелёную
  окантовку и выглядит кликабельной.
- Наведение: подсветка box-shadow сохраняется; при генерации кнопка
  задизейблена (opacity 0.5).
