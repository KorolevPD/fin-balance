# T-075: GigaChat — HTTP 404 «No such model» (устаревший идентификатор модели)

- Дата: 2026-09-07T18:00:00Z
- Владелец: opencode (основной агент)
- Ветка: feature/T-075-gigachat-model (от main)
- Предыдущая попытка: нет (новая задача; дефект после T-073/T-074, TLS уже пройден)

## Проблема

После успешного прохождения TLS очередная ошибка:

```
GigaChat: HTTP 404: {"status":404,"message":"No such model"}
```

## Диагноз

В `backend/app/ai/gigachat.py` константа `DEFAULT_MODEL = "GigaChat"` — это
устаревший идентификатор модели, который GigaChat API больше не принимает
→ 404 «No such model». TLS и OAuth работают (ошибка дошла до генерации).

Актуальные идентификаторы моделей (официальная документация, обновлено
17.07.2026, https://developers.sber.ru/docs/ru/gigachat/guides/selecting-a-model):

- `GigaChat-2`
- `GigaChat-2-Pro`
- `GigaChat-2-Max`
- `GigaChat-3-Ultra` (freemium для физлиц)

## Решение

Заменить `DEFAULT_MODEL = "GigaChat"` → `DEFAULT_MODEL = "GigaChat-2-Max"`
(флагманская модель, используется в официальных примерах запросов,
подходит обоим типам аккаунтов). Обновить тест `model == "GigaChat"`.
