# Задача T-060: Импорт не ждёт AI — фоновое обогащение (BackgroundTasks)

Владелец: основной агент
Дата: 2026-09-06T11:50:26Z
Статус: IN_PROGRESS

## Проблема

После загрузки файла дашборд с тратами и категориями не открывается,
пока ИИ «думает». Ожидание: мгновенно показать траты/категории, а ИИ
уже потом готовит советы.

## Первопричина

В `import_transactions` (`backend/app/routers/transactions.py:93-98`)
вызов `enrich_with_ai(...)` выполняется синхронно до сохранения и до
возврата ответа. `enrich_with_ai` отправляет все описания во внешний
AI-провайдер и ждёт ответ (таймаут до 60 c, `gemini.py:28`). Пока AI
не ответит, endpoint не отдаёт результат, а фронт (UploadModal) ждёт
ответ `POST /transactions/import` — поэтому дашборд не открывается.

## Признаки

- `transactions.py:93-98` — AI-вызов в критическом пути импорта.
- `ai_transactions.py:69-87` — `enrich_with_ai` вызывает
  `classify_descriptions` (сетевой AI-запрос).
- `gemini.py:28` — `timeout=60`.
- Баг проявляется только у пользователей с AI-ключом
  (`ai_transactions.py:69` — без ключа возвращает как есть).

## Минимальное исправление (BackgroundTasks)

1. Сохранять транзакции сразу с rule-based категориями (мгновенный ответ).
2. Запускать AI-обогащение в фоновой задаче FastAPI после ответа:
   `enrich_saved_transactions(db, *, family_id, user_id, source_file)`
   читает созданные выпиской транзакции и обновляет category/cleaned.
3. `tests/conftest.py`: переопределить `app.database.SessionLocal` на
   тестовый sessionmaker, чтобы фоновая задача работала с той же
   in-memory SQLite в тестах.

## Проверка

- `pytest` — 155 passed (в т.ч. `test_импорт_с_ai...`, подтверждает
  фоновое обогащение: импорт возвращает ответ, AI применяется в фоне).
- `ruff check` — чисто по затронутым файлам (app + tests).

## Реализация

- `ai_transactions.py`: добавлены `enrich_saved_transactions` (обновляет
  уже сохранённые транзакции) и `run_enrich_in_background`
  (открывает сессию через `database.SessionLocal` динамически).
- `routers/transactions.py`: из импорта убран синхронный `enrich_with_ai`;
  ответ возвращается сразу; обогащение запускается через
  `BackgroundTasks.add_task(run_enrich_in_background, ...)`.
- `tests/conftest.py`: в `session_factory` переопределён
  `database.SessionLocal` на тестовый sessionmaker (фон работает с той
  же in-memory SQLite).

Важно: `run_enrich_in_background` обращается к `database.SessionLocal`
через модуль (не `from ... import SessionLocal`), т.к. прямое импортирование
зафиксировало бы ссылку на Postgres-объект при импорте и сломало фон в тестах.

## Побочные эффекты

- При первом рендере после загрузки AI-категории могут ещё не
  примениться (появляются после завершения фона; при перезагрузке
  дашборда отразятся).
- Фоновая задача не блокирует ответ импорта.
