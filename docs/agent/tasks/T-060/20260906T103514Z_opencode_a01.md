# T-060 Попытка a01 — AI-анализ расходов через ключ пользователя

## Задача

Реализовать AI-интеграцию: пользователь вводит свой бесплатный API-ключ
(Gemini) в профиле. При загрузке выписки AI определяет категорию и генерирует
дружелюбное описание (оригинал остаётся в БД). На дашборде в блоке «Резерв»
выводится AI-совет для пользователя (семейный дашборд) с кнопкой «Новый
совет», советы сохраняются в БД и перелистываются.

## Решения заказчика

- Провайдер: Gemini (бесплатный ключ AI Studio), реестр провайдеров с
  OpenAI-совместимой прослойкой (задел под Groq/OpenRouter).
- Зависимости: cryptography (AES-GCM) и httpx — одобрены.
- Совет: на семейном дашборде генерируется совет (семейный скоуп), список
  в семье.
