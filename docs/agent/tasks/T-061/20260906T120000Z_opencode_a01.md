## Задача

Пользователь, подключив API-ключ Google AI Studio и открыв дашборд,
получает ошибку генерации совета:

```
Gemini: HTTP 404: { "error": { "code": 404,
"message": "This model models/gemini-2.0-flash is no longer available.
Please update your code to use models/gemini-3.6-flash ...",
"status": "NOT_FOUND" } }
```

## Диагностика

- Первопричина: Google отозвал модель `gemini-2.0-flash`.
- В коде модель жёстко зашита в `backend/app/ai/gemini.py:12`
  (`DEFAULT_MODEL = "gemini-2.0-flash"`).
- При генерации совета (`routers/ai.py`) / классификации импорта
  (`services/ai_transactions.py`) запрос идёт на
  `generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent`
  → Google отвечает 404 → `AIError` → 502 с текстом ошибки в UI.
- Для провайдера `gemini` `ai_base_url` не передаётся (Profile.js шлёт его
  только для `openai_compatible`), поэтому всегда используется `DEFAULT_MODEL`.

## План

1. Падающий тест: перехват URL запроса `httpx.post` при вызове
   `generate_advice` — assert, что URL содержит актуальную модель
   `gemini-3.6-flash` (до фикса в URL `gemini-2.0-flash` → тест падает).
2. Тест на воспроизведение 404: мок ответа со `status_code=404` и телом
   из отчёта → assert, что `generate_advice` бросает `AIError` с «HTTP 404».
3. Фикс: `DEFAULT_MODEL = "gemini-3.6-flash"` + обновление docstring.
4. Проверка: `pytest tests/test_ai.py`, полный `pytest`, `ruff check backend tests`.
