## Цель выполнения

Переместить создание/вступление в семью из профиля на дашборд:

1. В карточке «Общая сумма расходов» (`stat-card` на реальном дашборде
   семьи) разместить одну кнопку «Войти в/Создать семью».
2. Кнопка открывает новое модальное окно ПОВЕРХ других (как при загрузке
   файла: `modal-overlay` + `modal`, Esc/оверлей — закрытие).
3. В модалке сверху две вкладки «Создать» и «Войти»:
   - «Создать» — показывает код приглашения текущей (личной) семьи
     с кнопкой «Копировать»;
   - «Войти» — поле ввода чужого кода приглашения, отправка
     `POST /families/join` (семьи объединяются, владелец текущей становится
     участником целевой).
4. Блок «Семья» из профиля удаляется — управление семьёй переносится
   на дашборд.

Backend не изменяется: используются существующие эндпоинты
`GET /families/my`, `GET /families/{id}/members` (нет — участники в модалке
не выводятся, был только код), `POST /families/join`.

## Диагностика (до изменений)

- Блок «Семья» — `frontend/src/pages/Profile.js`, строки 202–260
  (код приглашения, копирование, список участников, форма вступления).
- Карточка «Общая сумма расходов» — `frontend/src/pages/Dashboard.js`,
  строки 258–267 (`section.summary-cards` → `div.stat-card`), выводится
  только при `hasData`.
- Модальные окна уже есть: `UploadModal.js`, `TransactionEditModal.js`,
  общие стили `.modal-overlay` / `.modal` в `styles.css`.
- После `POST /families/join` целевая семья остаётся, исходная (текущая)
  удаляется, транзакции переносятся в целевую → URL `/family/{old}/dashboard`
  становится невалидным, поэтому после успешного вступления нужно
  редиректить на `/family/{target.id}/dashboard`.

## Решение

1. Новый компонент `frontend/src/components/FamilyModal.js`:
   - props: `onClose`, `onJoined(nextFamily)`.
   - При открытии загружает `GET /families/my`, берёт первую семью.
   - Вкладки «Создать» / «Войти» вверху окна (`role="tablist"`),
     переключение по клику/клавишам.
   - «Создать»: код приглашения своей семьи + «Копировать» (clipboard).
   - «Войти»: поле `invite_code`, кнопка «Присоединиться», отправка
     `POST /families/join`, на успех — `onJoined(res.data)`.
   - Закрытие: Esc, клик по оверлею, кнопка «Отмена» (не во время запроса).
2. `frontend/src/pages/Dashboard.js`:
   - В `stat-card` под значением суммы — кнопка «Войти в/Создать семью»
     (`setFamilyOpen(true)`).
   - Рендер `FamilyModal` при `familyOpen`; `onJoined` → navigate на
     `/family/{next.id}/dashboard`.
3. `frontend/src/pages/Profile.js`: удалить карточку «Семья» и связанные
   стейты/обработчики/стили-использования (перенос на дашборд).
4. `frontend/src/styles.css`: стили `.modal-tabs`, `.modal-tab[.active]`,
   `.stat-card .btn` / `.summary-actions`; переиспользовать `.family-code`,
   `.invite-row`, `.copy-btn`. Убрать неиспользуемые `.member-list`,
   `.member-email`, `.member-role` (если больше нигде не используются).
5. `npm run check` → пересборка `frontend/build/`.
