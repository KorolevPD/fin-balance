# T-011: Авторизация Frontend

## Попытка: a01
## Время: 2026-09-04T18:00:00Z
## Исполнитель: frontend-агент

## Что сделано

1. Создана ветка `feat/T-011-auth-frontend`
2. Обновлён `package.json` - добавлен `react-scripts` в зависимости
3. Создана структура React-приложения:
   - `src/index.js` - точка входа
   - `src/App.js` - главный компонент с маршрутизацией
   - `src/api.js` - axios-инстанс с JWT-авторизацией
   - `src/context/AuthContext.js` - контекст авторизации
   - `src/pages/Login.js` - страница входа
   - `src/pages/Register.js` - страница регистрации
   - `src/components/PrivateRoute.js` - защищённый маршрут
4. Реализовано:
   - Сохранение JWT в localStorage
   - Автоматическая отправка токена в заголовке Authorization
   - Обработка 401 ошибки (очистка токена, редирект на /login)
   - Валидация формы регистрации (совпадение паролей, минимальная длина)
   - Русскоязычные подписи и сообщения
   - Связанные label с полями ввода
