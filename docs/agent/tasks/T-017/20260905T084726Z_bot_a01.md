## Блокеры и риски

- Аутентификация эндпоинта `/api/bot/upload` основана на `telegram_id` (как и существующие `/api/bot/confirm`, `/api/bot/me`). Это осознанное упрощение MVP: бот не имеет JWT, все участники семьи равны. При необходимости усилить — ввести разделяемый секрет для бота (X-Bot-Token) с поднятием в docker-compose.
- Если пользователь состоит в нескольких семьях, файл импортируется в первую по времени вступления (`FamilyMember` берётся `.first()`). В MVP семья одна на пользователя, поведение задокументировано.
- Полная проверка приёма файла в Telegram требует реального BOT_TOKEN; покрыто тестами эндпоинта и логики бота.
