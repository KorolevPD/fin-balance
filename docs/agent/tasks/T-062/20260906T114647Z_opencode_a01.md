# T-062 — Условный рендеринг аватара (фото профиля)

Дата: 2026-09-06T11:46:47Z
Исполнитель: opencode
Попытка: a01

## Задача

Реализовать условный рендеринг аватара (фото профиля): если у пользователя нет фото (avatar пустой или null), выводить картинку `fin-balance\avatar.jpg`. Если пользователь устанавливал фото — выводить его. Остальное не менять.

## Предыдущая попытка

Попыток нет, задача новая.

## План

1. Скопировать `avatar.jpg` из корня проекта в `frontend/public/avatar.jpg` (общедоступный статический файл).
2. В `frontend/src/components/Layout.js` (шапка): вместо ветки «буква-заглушка» при пустом `avatar` выводить `/avatar.jpg`.
3. В `frontend/src/pages/Profile.js` (профиль): аналогично — при пустом `avatar` выводить `/avatar.jpg` вместо «буквы-плейсхолдера».
4. Проверить `npm run check`.

## Что сделано

1. Скопирован файл `avatar.jpg` в `frontend/public/avatar.jpg`.
2. `Layout.js`: строка рендеринга аватара в шапке заменена на единый `<img>` с `src={preview || '/avatar.jpg'}`. Ветка со `span.header-avatar-letter` удалена.
3. `Profile.js`: в блоке «Фото профиля» вместо условной ветки `preview ? <img> : <div class="avatar-placeholder">` теперь единый `<img>` с `src={preview || '/avatar.jpg'}`.

Логика прежняя: `avatarUrl()` возвращает `null`, если avatar пуст/отсутствует, и URL загруженного фото — если установлено. Следовательно `preview || '/avatar.jpg'` корректно выбирает дефолтную картинку при отсутствии фото и пользовательское фото при его наличии.
