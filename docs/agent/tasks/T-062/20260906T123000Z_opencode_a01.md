# T-062: Фикс: дата регистрации отображается как «дд.мм.гггг»

**Попытка:** a01
**Владелец:** opencode
**Начало:** 2026-09-06T12:30:00Z

## Предыдущая попытка

Нет (новая задача).

## Что сделано

- Исследована первопричина: `formatDate()` в `Profile.js` возвращает `"06.09.2026"` (точки), а `<input type="date">` требует формат `YYYY-MM-DD`. Браузер игнорирует невалидное значение и показывает плейсхолдер.
- Бэкенд работает корректно: колонка `created_at` есть в модели, миграции, Pydantic-схеме и `/auth/me`.

## Точный следующий шаг

Заменить `type: 'date'` на `type: 'text'` в `READONLY_FIELDS` (строка 12 `Profile.js`), проверить `npm run check`, коммит, ветка, PR.
