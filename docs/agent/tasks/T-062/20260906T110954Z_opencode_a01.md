## Цель выполнения

В блоке «Члены семьи» на дашборде добавить кнопку «Распустить семью»
в правом нижнем углу. Условия (уточнены у пользователя):

1. Кнопка видна, когда в семье **≥ 2 человек** (владелец + хотя бы один
   участник).
2. Кнопку видит и может использовать **только владелец** (role owner).
3. При нажатии все участники (кроме владельца) покидают семью, а их
   **операции удаляются вместе с их исправлениями (UserCorrection)**.

## Диагностика (до изменений)

- Список «Члены семьи» — `frontend/src/pages/Dashboard.js`,
  `section.card.demo-block[aria-label=«Члены семьи»]` (строки 321–343):
  таблица `Имя | Траты` на основе `summary.family_members`.
- `summary.family_members` (`backend/app/services/analytics.py`, строки
  116–125) не содержит `role` → для определения владельца фронту нужно
  добавить `role` в сводку.
- Удаление транзакций с их UserCorrection уже реализовано в
  `DELETE /families/{id}/transactions` (`transactions.py`, строки 184–190) —
  повторить тот же паттерн при роспуске.
- Backend не имеет эндпоинта для удаления участников → нужен новый
  эндпоинт роспуска семьи.

## Решение

1. **Backend** `backend/app/services/analytics.py`: в каждый элемент
   `family_members` добавить `role` участника (для определения владельца
   на фронте без лишних запросов).
2. **Backend** `backend/app/routers/families.py`: новый эндпоинт
   `POST /families/{family_id}/disband`:
   - `404` — семья не найдена; `403` — нет доступа / пользователь не
     владелец;
   - удаляет всех участников с ролью не `owner` (Membership),
   - удаляет их транзакции вместе с `UserCorrection`,
   - возвращает `{removed, remaining}`.
   Если удалять некого — `{removed: 0, remaining: 1}`.
3. **Frontend** `frontend/src/pages/Dashboard.js`:
   - определить владельца: из `summary.family_members` запись с
     `user_id === user.id` и `role === 'owner'`;
   - кнопка «Распустить семью» видна, когда текущий пользователь —
     владелец и `members.length >= 2`;
   - размещение — справа снизу внутри блока «Члены семьи» (футер карточки,
     `text-align: right`);
   - по клику — `window.confirm`, затем `POST /families/{id}/disband`,
     по успеху `loadData()`.
4. **Frontend** `frontend/src/styles.css`: стиль футера карточки
   `.members-footer` (или аналог) для выравнивания кнопки вправо.
5. **Тесты**:
   - `tests/test_analytics_summary.py`: проверить наличие `role` в
     `family_members`;
   - `tests/test_families.py`: новый класс `TestDisbandFamily`:
     роспуск оставляет только владельца и удаляет операции вышедших;
     не-владелец получает 403; семья не найдена → 404.
6. `npm run check` (frontend) + `pytest` (backend).
