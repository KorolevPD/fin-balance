# T-068 Попытка a01 — ИИ-перераспределение операций из категории «Прочее»

Владелец: opencode
Дата: 2026-09-07T09:21:25Z
Статус: IN_PROGRESS
Ветка: feature/T-068-ai-reclassify-prochee

## Задача

Все траты, которые попадают в категорию «Прочее», должны быть проанализированы
ИИ и распределены по другим категориям. Решения заказчика:

- ИИ анализирует **только** операции из «Прочее» и распределяет их в другие
  категории. Без AI-ключа / при ошибке ИИ операции остаются «Прочее».
- Из допустимых для ИИ категорий **убрать «Прочее»** и убрать фразу
  «если не уверен — используй Прочее», чтобы ИИ вынужден был выбрать
  реальную категорию.
- Без настроенного AI-ключа ничего дополнительно не показывать — операции
  остаются «Прочее».
