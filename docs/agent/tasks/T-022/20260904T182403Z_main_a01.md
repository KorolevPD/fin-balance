# T-022: Исправление багов — несовместимость бэкенда и фронтенда

## Попытка: a01
## Время: 2026-09-04T18:24:03Z
## Исполнитель: основной агент

## Проблема

При запуске не работала регистрация. Найдены три причины:

1. **`backend/main.py` падал при старте** — merge `94f5e8a` (feature/T-007-csv-upload)
   потерял импорт `from app.routers.uploads import router as upload_router`, но оставил
   `app.include_router(upload_router)` → `NameError: name 'upload_router' is not defined`.
   Бэкенд не стартовал вообще (воспроизведено через `from main import app`).
2. **Расхождение URL** — фронтенд (`frontend/src/api.js`, `AuthContext.js`, страницы)
   ходит в `POST /api/auth/register`, `POST /api/auth/login`, `GET /api/auth/me`,
   `POST /api/families`, `POST /api/families/join`, `GET /api/families/my`,
   `GET /api/families/{id}/members`, `POST /api/upload`, а бэкенд отдавал те же
   маршруты без префиксов `/api` и `/auth` на корне.
3. **`/register` возвращал объект пользователя**, а фронтенд ожидает
   `access_token` (далее делает `GET /api/auth/me`).

## Что сделано

- `backend/main.py`: добавлен импорт роутера `uploads`, все роутеры подключены с
  префиксом `/api`.
- `backend/app/routers/auth.py`: добавлен `prefix="/auth"`; ответ `/register`
  изменён на `TokenOut` (`access_token` + `token_type`), как ожидает фронтенд.
- `tests/test_upload_backend.py`: пути обновлены с `/upload` на `/api/upload`.
- Новый `tests/test_api_routes.py`: удостоверяет, что приложение импортируется,
  все ожидаемые фронтендом маршруты существуют, и `/register` отдаёт токен.

## Проверка

- `pytest tests/`: 23 passed (маршруты, upload, парсер).
- `ruff check` по изменённым файлам: All checks passed.
- Локальный запуск `uvicorn main:app`: `/health` отвечает `{"status":"healthy"}`,
  OpenAPI содержит 9 ожидаемых маршрутов под `/api`, CORS-preflight для
  origin `http://localhost:3000` проходит, `/api/auth/me` без токена → 401.
- Замечание: полный сценарий регистрации в БД локально не прогнан — в окружении
  нет запущенного PostgreSQL (docker-демон выключен, системный postgres не установлен).

## Риски и заметки

- В `docker-compose.yml` команда бэкенда — только `uvicorn main:app`. Если таблицы
  не созданы (не выполнен `alembic upgrade head`), регистрация упадёт с ошибкой
  «relation users does not exist». Ручной запуск требует предварительно выполнить
  `alembic upgrade head` из каталога `backend/`.
- В CI workflow отсутствует job с `pytest` (есть только ruff и `npm test`); pytest
  запускается только локально, из корня репозитория (conftest добавляет `backend/` в sys.path).
