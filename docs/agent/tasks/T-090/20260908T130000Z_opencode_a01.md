# T-090 (a01): сумма расходов за 30 дней в верхнем блоке дашборда

- Дата: 2026-09-08T13:00:00Z
- Владелец: opencode
- Ветка: feature/T-090-dashboard-total-30d

## Задача

Верхний блок дашборда должен показывать сумму расходов за последние
30 дней (а не за весь период), текст заменить на
«Общая сумма расходов за 30 дней».

## Анализ

- `frontend/src/pages/Dashboard.js:329` — текст «Общая сумма расходов»;
- `:332` — `formatAmountPlain(summary.total_amount)` — сумма за весь период;
- сводка из API (`get_family_summary`) содержит `daily`
  (`[{ day, amount }, ...]`, только дни с операциями-расходами).

## Решение

На фронтенде из `summary.daily` вычисляется сумма за скользящий период в
30 календарных дней: берётся последняя дата в данных, окно `[last − 29, last]`
(строки ISO сравниваются лексикографически). Результат используется в
верхнем блоке. Если `daily` пуст — фолбэк на прежнее `total_amount`.

Агрегаты категорий/чарта не меняются (задача не касается их долей).

## Файлы

- `frontend/src/pages/Dashboard.js`
- `frontend/build/*` — пересборка (отдельный build-коммит)

## Проверка

- `npm run check`, `CI=true npx react-scripts test`.
- Ручной сценарий (браузер):
  1. Дашборд с выпиской, содержащей операции за последние 30 дней:
     верхний блок показывает их сумму, текст «Общая сумма расходов
     за 30 дней».
  2. Выписка, чьи операции старше 30 дней: блок показывает 0,00 ₽
     (или корректную сумму из окна), проценты категорий без изменений.
