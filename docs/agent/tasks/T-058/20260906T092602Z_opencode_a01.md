## Цель выполнения

В окне «Банковские выписки» кнопка «Удалить» у каждой выписки расположена
слишком близко к колонке «Операций». Требуется отцентровать её по горизонтали
в пространстве между колонкой «Операций» и правым краем окна.

## Диагностика (до изменений)

- Блок «Банковские выписки» — `frontend/src/pages/Dashboard.js`, таблица
  `data-table` внутри `section.card demo-block` (строки 339–368).
- Заголовки таблицы: `Файл | Период | Операций | <пусто>`. Колонка
  «Операций» — `class="num"` (выравнивание вправо).
- Кнопка «Удалить» лежит в `td.actions-cell` — стиль `.actions-cell`
  (`frontend/src/styles.css`, строка 792) задаёт `text-align: right`.
  Из-за выравнивания вправо кнопка прижата к границе колонки «Операций».

## Решение

Кнопку «Удалить» в таблице выписок перенести из ячейки с классом
`actions-cell` в ячейку с новым классом `.files-remove-cell` (сохранить
`white-space: nowrap`), задать в `frontend/src/styles.css` этому классу
`text-align: center` — кнопка окажется по центру пространства между колонкой
«Операций» (последняя содержательная колонка) и правым краем карточки/окна.

Общее для реального дашборда (`Dashboard.js`) и демо-дашборда
(`DemoDashboard.js`, таблица выписок с `showDelete`). На других экранах
(`Операции`, список операций дашборда) класс `actions-cell` не меняется —
кнопки «Изменить» остаются с выравниванием вправо.

При пустом списке выписок (`files.length === 0`) кнопка не выводится —
изменение не влияет на пустое состояние.
