## Задача

PR #51 (T-045) показал конфликт с `main`. Причина: после `git merge origin/main`
в сессии потерялся MERGE_HEAD (коммит `a2a7b30` вышел плоским, с одним родителем,
без интеграции `af1d8ce`), поэтому `origin/main` не является предком ветки.

## Решение

1. Откатить плоский коммит `a2a7b30` (`git reset --hard d8052b9`, `git clean` build).
2. Повторно `git merge origin/main` и резолв в одной команде:
   - конфликты только в `frontend/build` (hash-файлы) → взять версию `origin/main`;
   - `frontend/src/styles.css` мёржится чисто (изменения main — `.card-header-actions`,
     мои — `.demo-grid { margin-bottom: 24px }`, не пересекаются);
   - после резолва пересобрать `npm run check` из смерженного исходника,
     чтобы build содержал обе правки.
3. Коммит-merge с двумя родителями → `main` становится предком ветки → PR чист.
4. Force-push (ветка PR, до этого пушил только я).

## Проверка

- В собранном CSS присутствуют и `.demo-grid{margin-bottom:24px}`, и
  `.card-header-actions`.
- `git merge-base --is-ancestor origin/main HEAD` = yes.
- `gh pr view 51` → mergeable=CLEAN.
