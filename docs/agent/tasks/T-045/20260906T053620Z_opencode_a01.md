## Цель выполнения

На дашборде (`Dashboard.js`) отступ между рядом блоков «Резерв» + «Банковские
выписки» (вторая строка `.demo-grid`) и расположенным ниже блоком «Расходы по
категориям» должен быть таким же, как между другими рядами блоков (24px через
`gap` сетки).

## Диагностика (до изменений)

- `frontend/src/styles.css`, `.demo-grid`: `gap: 24px` между рядов блоков.
- Ячейки сетки — `.card.demo-block` с `margin-bottom: 0` (перекрытие `.card`).
- Блок «Расходы по категориям» — отдельный `section.card` сразу после закрытия
  `.demo-grid` в `Dashboard.js` (строка 327). У него нет `margin-top`,
  а у `.demo-grid` нет `margin-bottom` → фактический отступ после последнего
  ряда сетки равен 0, тогда как между рядами внутри сетки — 24px.

## Решение

Добавить в `.demo-grid` (`frontend/src/styles.css`) отступ снизу `margin-bottom: 24px`,
равный `gap` сетки. Это выравнивает расстояние между рядом «Резерв» + «Банковские
выписки» и блоком «Расходы по категориям» с расстоянием между другими рядами.
Изменение общее для всех страниц, использующих `.demo-grid` (`Dashboard.js`,
`DemoDashboard.js`), и для мобильного вида (1 колонка) тоже даёт 24px.
