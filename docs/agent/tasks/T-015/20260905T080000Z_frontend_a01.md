- `PATCH /api/families/{family_id}/transactions/{transaction_id}` →
  тело: `{"cleaned_description": "…", "category": "…"}`
  ответ: обновлённая транзакция (тот же формат, что в списке дашборда).

## Критерии приёмки (3)

1. Модальное окно открывается из списка операций дашборда («Изменить»), поля
   «Название» и «Категория» заполнены текущими значениями операции.
2. Категория выбирается из списка, название редактируется; «Сохранить»
   отправляет PATCH-запрос; при успехе список операций и сводка обновляются.
3. Корректная работа окна: «Отмена», закрытие по Esc и клику на фон,
   сообщение об ошибке при неудачном сохранении, название не может быть пустым.

## Ручной сценарий проверки

Зависим от бэкенда: после реализации PATCH-эндпоинта (T-010):
1. Открыть дашборд семьи → список операций → нажать «Изменить».
2. В окне видны текущие название и категория; значения можно поменять.
3. «Сохранить» → окно закрывается, строка и сводка обновились.
4. Очистить название → «Сохранить» → показано сообщение о пустом названии.
5. «Отмена», Esc и клик по фону закрывают окно.
