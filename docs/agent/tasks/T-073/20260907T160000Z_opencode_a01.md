# T-073: GigaChat — TLS CERTIFICATE_VERIFY_FAILED (корневой сертификат НУЦ Минцифры)

- Дата: 2026-09-07T16:00:00Z
- Владелец: opencode (основной агент)
- Ветка: feature/T-073-gigachat-ca-bundle
- Предыдущая попытка: нет (новая задача; порождена дефектом, найденным в T-072)

## Задача пользователя

Диагностировать ошибку генерации совета:

```
Ошибка генерации совета: GigaChat: сеть/таймаут при получении токена:
[SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed:
self-signed certificate in certificate chain (_ssl.c:1016)
Возможно, требуются сертификаты НУЦ Минцифры (см. deploy/DEPLOY.md).
```

Пользователь подтвердил минимальное исправление: **оставить TLS-проверку включённой**,
добавить переменную окружения `GIGACHAT_CA_BUNDLE` (путь к PEM-бандлу с корневым
сертификатом НУЦ Минцифры) и передавать её как `verify=...` в httpx-запросы GigaChat.

## Диагноз (подтверждён)

- Эндпоинты `ngw.devices.sberbank.ru:9443` и `api.giga.chat` отдают цепочку с
  самоподписанным корнем НУЦ Минцифры, которого нет в trust-store httpx
  (certifi / Debian `python:3.11-slim`).
- `httpx.post` в `gigachat.py` вызывался без `verify=...` → default = certifi.
- Ошибка возникает на этапе `_access_token` (до OAuth), валидность ключа не проверяется.
- `DEPLOY.md` требование описал, но механизма доставки сертификата нет.

## План правок

- `backend/app/ai/gigachat.py`:
  - хелпер `_cacert()`: читает `GIGACHAT_CA_BUNDLE` (путь к PEM) → путь или `True`;
  - `verify=_cacert()` в обоих `httpx.post` (oauth и chat/completions);
  - обновить `_SSL_HINT` на конкретное действие (переменная `GIGACHAT_CA_BUNDLE`).
- `docker-compose.yml`, `docker-compose.prod.yml`:
  - проброс env `GIGACHAT_CA_BUNDLE=${GIGACHAT_CA_BUNDLE:-}`;
  - закомментированный volume-монтаж сертификата в контейнер с пояснением.
- `.env.example`, `backend/.env.example`: переменная `GIGACHAT_CA_BUNDLE`.
- `deploy/DEPLOY.md`: как получить корневой сертификат НУЦ, как задать переменную
  локально и на сервере (секрет), как размонтировать в контейнер.
- `tests/test_ai.py`: фейковый `httpx.SSLError` → AIError с подсказкой про
  `GIGACHAT_CA_BUNDLE`; тест, что `verify` берёт путь из env.

## Ручной сценарий (не проверен — нет доступа к сети Сбера)
