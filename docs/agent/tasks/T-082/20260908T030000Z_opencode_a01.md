# T-082: вернуть подписи на секторах диаграммы «Траты по категориям»

- Дата: 2026-09-08T03:00:00Z
- Владелец: opencode
- Ветка: feature/T-082-restore-donut-labels (база — feature/T-081-category-chart-height)
- Предыдущая попытка: нет

## Задача пользователя

На дашборде вернуть подписи для кусочков диаграммы «Траты по категориям».
В прошлых версиях приложения подписи были и не перемешивались (не накладывались)
между собой.

## Контекст

- В T-059 (коммиты 5bf297d, f673647) были введены подписи секторов:
  - `label={shouldLabelCategory}` — название категории, если её доля >= 1%;
  - `labelLine={shouldLabelLine}` — линия-выноска (`Curve`) тоже только для
    категорий >= 1%;
  - это и есть «прошлые версии», где подписи были и не мешали друг другу.
- В моей ветке T-081 (PR #114, пока не смержен в main) эти подписи были
  удалены, чтобы исключить выход надписей за рамки блока; высота блока
  увеличена до 308px, легенда размещена по нижнему краю.
- Задача T-082 — вернуть подписи секторов поверх изменений T-081 (унаследовать
  увеличение высоты и легенду, вернуть label/labelLine).

## Изменения (frontend/src/pages/Dashboard.js)

- Вернуть в `Pie` атрибуты `label={shouldLabelCategory}` и
  `labelLine={shouldLabelLine}`.
- Вернуть вычисления и хелперы:
  - `chartTotal = chartCategories.reduce(...)`;
  - `shareOf(entry)` — доля категории в %;
  - `shouldLabelCategory(entry)` — `entry.category`, если `shareOf >= 1`, иначе null;
  - `shouldLabelLine(props)` — `<Curve type="linear" {...props} className="recharts-pie-label-line" />`,
    если `shareOf >= 1`, иначе null.
- Вернуть импорт `Curve` из `recharts`.

## Итог попытки a01 (выполнена, 2026-09-08)

### Изменения

По сравнению с базой (feature/T-081-category-chart-height):

- `frontend/src/pages/Dashboard.js`:

  - вернуты `chartTotal`, `shareOf`, `shouldLabelCategory`, `shouldLabelLine`;
  - вернута импорт `Curve` из `recharts`.
- Унаследованы изменения T-081 (высота 308px, легенда по нижнему краю),
  так что подписи секторов теперь сочетаются с увеличенным блоком и не
  наезжают на легенду/границы.

### Ручной сценарий (браузер; требуется проверка пользователем)

- В блоке «Траты по категориям» у каждого сектора с долей >= 1% снова видна
  подпись категории и линия-выноска; категории < 1% подписи не получают.
- Подписи не накладываются друг на друга и не выходят за рамки блока.
