# T-067 Попытка a01 — Кнопка на главной странице: «Зарегистрироваться» + «Уже есть аккаунт? Войти»

## Цель выполнения

На главной странице (Landing) для незарегистрированных пользователей:
- кнопку «Зарегистрироваться/войти» заменить на «Зарегистрироваться»;
- снизу добавить текст-ссылку «Уже есть аккаунт? Войти».

## Диагностика (до изменений)

- `frontend/src/pages/Landing.js` строка 29–31:
  ```jsx
  <Link to="/register" className="landing-btn">
    Зарегистрироваться/войти
  </Link>
  ```
- Кнопка `Link` с классом `.landing-btn` — внутри `.landing-window`
  (flex-колонка, `align-self: center`).
- В проекте уже используется стиль текста-ссылки `auth-link` (Login.js/Register.js):
  `margin-top: 16px; text-align: center; font-size: 0.9rem;`

## Решение

В `Landing.js` заменить текст кнопки на «Зарегистрироваться» и после кнопки
добавить ссылку на `/login`:

```jsx
<Link to="/register" className="landing-btn">
  Зарегистрироваться
</Link>
<p className="landing-auth-link">
  Уже есть аккаунт? <Link to="/login">Войти</Link>
</p>
```

В `styles.css` добавить:
```css
.landing-auth-link {
  margin: 16px 0 0;
  text-align: center;
  font-size: 0.95rem;
  color: #14213d;
}

.landing-auth-link a {
  color: #5b5bea;
  font-weight: 600;
  text-decoration: none;
}

.landing-auth-link a:hover {
  text-decoration: underline;
}
```
