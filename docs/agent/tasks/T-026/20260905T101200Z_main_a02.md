## Уточнение направления

Первая итерация делала универсальный адаптив с упором на мобильную ширину. По уточнению заказчика целевой формат — **широкоформатный десктоп** (шапка «как на мобильном» выглядела из-за узких контейнеров контента).

## Что сделано

Итоговая раскладка шапки (десктоп):
- Логотип `logo.png` — в левом углу (`justify-self: start`), кликабелен (`<Link to="/">`).
- Кнопки «Создать семью» и «Загрузить» — по центру (`justify-self: center`).
- Вход в аккаунт (email + «Выйти») — в правом углу (`justify-self: end`).
- Сетка шапки: `grid-template-columns: 1fr auto 1fr` — колонки растягиваются на всю ширину экрана.

Адаптив под широкоформатный десктоп (`frontend/src/styles.css`):
- `.dashboard-main` padding: `32px 48px` (поля по бокам под широкий экран).
- `.page` max-width: `720px` → `1200px` (главная, семьи, загрузка).
- `.dashboard-page` max-width: `960px` → `1400px` (дашборд на широком мониторе).
- `@media (min-width: 1400px)`: шапка получает больший горизонтальный padding `16px 64px`.
- Сохранён `@media (max-width: 720px)` как fallback для мобильных (кнопки на вторую строку, email скрыт).

## Результат проверки

- `npm run check` — Compiled successfully.
- Ручной сценарий в браузере: записать после визуального просмотра (широкий десктоп + узкий экран).
