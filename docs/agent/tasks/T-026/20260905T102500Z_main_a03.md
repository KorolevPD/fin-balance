# T-026: Шапка на всю ширину экрана (итерация 3 — фикс корневой причины)

**Владелец:** основной агент
**Дата:** 2026-09-05T10:25:00Z
**Ветка:** `feature/adaptive-header`
**Предыдущая попытка:** `docs/agent/tasks/T-026/20260905T101200Z_main_a02.md`

## Проблема

После `docker compose up --build` шапка отображалась узкой полоской по центру,
а не на всю ширину монитора.

## Корневая причина

В `frontend/src/styles.css` было:

```css
body {
  display: grid;
  place-items: center;
}
```

`place-items: center` (justify-items: center) заставлял grid-элемент `#root`
сжиматься до ширины содержимого и центрироваться. Внутри `#root` лежат
`.dashboard` (весь приклад включая шапку) и `.auth-form` — поэтому шапка
и весь сайт «схлопывались» в узкую колонку.

## Решение

`frontend/src/styles.css`:

```css
body {
  margin: 0;
  min-height: 100vh;
}

#root {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}
```

- `.dashboard { width: 100% }` теперь растягивается на всю ширину
  (дочерний элемент флекс-колонки, cross-axis stretch) — шапка занимает
  весь экран.
- `.auth-form { margin: auto }` по-прежнему центрирует формы
  входа/регистрации (auto-поля перекрывают stretch).

## Результат проверки

- `npm run check` — Compiled successfully.
- В собранном CSS (проверено grep по `build/static/css`): `body` без
  центрирования, `#root` — flex-колонка на всю ширину,
  `.dashboard { min-height:100vh; width:100% }`,
  `.dashboard-header { grid-template-columns:1fr auto 1fr; ... }`.
- Ручной сценарий: записать после `docker compose up --build` и открытия в браузере.

## Точный следующий шаг

Пересобрать образ nginx (`docker compose up --build`), открыть сайт: шапка
на всю ширину монитора, логотип слева, «Загрузить»/«Создать семью» по центру,
вход в аккаунт справа.
