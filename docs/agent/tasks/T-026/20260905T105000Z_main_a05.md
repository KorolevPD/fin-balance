# T-026: Шапка — «Выйти»/почта строго в правый угол (итерация 5)

**Владелец:** основной агент
**Дата:** 2026-09-05T10:50:00Z
**Ветка:** `feature/adaptive-header`
**Предыдущая попытка:** `docs/agent/tasks/T-026/20260905T104000Z_main_a04.md`

## Проблема

Почта и кнопка «Выйти» отображались по центру, рядом с навигацией,
а не в правом углу.

## Причина

В `Layout.js` блок `.user-info` лежал ВНУТРИ `.header-actions`, который
цепочкой `justify-self: center` центрировался целиком. Поэтому email
и «Выйти» оказывались сразу справа от навигации.

## Решение

- `Layout.js`: убрана обёртка `.header-actions`. `.logo-link`,
  `.dashboard-nav` и `.user-info` — три прямых ребёнка сетки шапки.
- `styles.css`:
  - `.dashboard-header { grid-template-columns: 1fr auto 1fr }`
  - `.logo-link { justify-self: start }`
  - `.dashboard-nav { justify-self: center }`
  - `.user-info { justify-self: end }`
  - удалён стиль `.header-actions`; в мобильном медиа-запросе
    `.header-actions` заменён на `.dashboard-nav`.

## Результат проверки

- `npm run check` — Compiled successfully.
- В собранном CSS (grep по `build/static/css`):
  `.dashboard-header{grid-template-columns:1fr auto 1fr...}`,
  `.user-info{...justify-self:end}`,
  `.dashboard-nav{...justify-self:center}`.
- Ручная проверка в браузере: записать после пересборки.

## Точный следующий шаг

`docker compose up --build`, визуальная проверка: логотип слева, навигация
по центру, почта + «Выйти» справа в углу.
