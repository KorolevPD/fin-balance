**Владелец:** основной агент
**Дата:** 2026-09-05T10:03:24Z

## Цель

Сделать шапку сайта адаптивной. Ранее шапка сверстана «на мобильное устройство». Требуется:

1. Основные кнопки «Загрузить» и «Создать семью» разместить по центру.
2. Логотип `logo.png` разместить в углу, сделать кликабельным (переход пока никуда — заглушка `#`).
3. Вход в аккаунт разместить справа в углу.

## Что сделано

- Создана ветка `feature/adaptive-header` из `main`.
- `logo.png` скопирован в `frontend/public/logo.png`.
- Обновлён `frontend/src/components/Layout.js`:
  - Логотип-изображение `logo.png` слева, обёрнут в кликабельный `<Link to="/">`.
  - Навигация (`Моя семья`, `Загрузить файл`) по центру.
  - Блок входа в аккаунт (`user-info`) справа.
- Обновлён `frontend/src/styles.css`:
  - `.dashboard-header` — центрирование по центру, логотип фиксирован слева, вход справа (grid-сетка).
  - Логотип `.logo` с фиксированной высотой.
  - Медиа-запрос для мобильных устройств (сворачивание строк).
