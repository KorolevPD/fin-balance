# T-039: Таблица «Расходы по категориям» — сортировка и категория «Прочее»

**Дата:** 2026-09-05T17:00:00Z
**Исполнитель:** opencode
**Ветка:** feature/T-039-category-table-sort

## Задача

На дашборде семьи (Dashboard.js):
1. В таблице «Расходы по категориям» добавлена категория «Прочее», если её нет
   в ответе бэкенда (строки с нулевой суммой, когда операций «Прочее» нет).
2. Колонки «Сумма», «Операций», «Доля» и «Категория» стали кликабельными —
   сортировка с переключением направления (▲/▼) по аналогии с T-038.

## Изменения

- `frontend/src/pages/Dashboard.js`:
  - добавлены state `catSortBy` (по умолчанию `amount`) и `catSortDir`
    (по умолчанию `desc`) и обработчик `handleCatSort(key)`;
  - категории сортируются через `useMemo` по выбранной колонке: сумма,
    количество операций, доля или название категории;
  - если в `by_category` нет категории «Прочее», она добавляется с нулевыми
    значениями, чтобы таблица всегда показывала эту категорию;
  - пай-чарт использует `chartCategories` (только категории с ненулевой суммой),
    чтобы нулевая строка «Прочее» не создавала пустой срез;
  - заголовки таблицы снабжены `aria-sort` и кнопками-сортировками.
