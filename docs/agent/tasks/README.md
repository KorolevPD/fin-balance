# Файлы выполнения задач

Перед **каждой** попыткой выполнения создавайте новый файл внутри каталога задачи:

```text
docs/agent/tasks/T-003/20260903T101530Z_storage_a01.md
```

Формат имени:

```text
YYYYMMDDTHHMMSSZ_<OWNER>_aNN.md
```

- временная метка записывается в UTC до секунд;
- `<OWNER>` — `main`, `reviewer`, `storage`, `tests` и т. п.;
- `aNN` — номер попытки данного исполнителя;
- если имя уже занято, увеличьте `aNN`;
- новая сессия или новый субагент создаёт новый файл;
- старые файлы не перезаписываются.

Timestamp-файл содержит цель, scope, критерии, изменённые файлы, команды, результаты, блокеры, точный следующий шаг, ссылку на предыдущую попытку и `SUBAGENT_HANDOFF`.

Субагент обновляет только свой файл. Центральный `TASKS.md` обновляет координатор после проверки diff и тестов.
