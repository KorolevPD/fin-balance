# T-086 (a01): упрощение блока «Семья» в профиле

- Дата: 2026-09-08T08:00:00Z
- Владелец: opencode
- Ветка: feature/T-086-simplify-family-block
- Задача: сделать интерфейс раздела «Семья» понятным, минималистичным и
  ненагруженным (из PRODUCT.md: «Семья» — профиль пользователя).

## Требования задачи

1. Код приглашения:
   — если в семье нет других участников (members.length <= 1), показывать
     строку «Код приглашения: ХХХХХХХХ»;
   — код — бОльшим размером шрифта и фирменным зелёным (#24a647);
   — кнопка — белая, в виде иконки «скопировать»;
   — при нажатии на код он копируется.
2. Убрать описание «Семья создаётся автоматически при регистрации. По коду
   приглашения группы объединяются в общий семейный бюджет (до 5 участников).»
3. Кнопки «Присоединиться к семье» и «Выйти из семьи» объединить в одну строку.
4. Если участник один (только текущий пользователь):
   — кнопку «Выйти из семьи» не показывать;
   — заголовок «Участники (1)» не показывать;
   — текущего пользователя из списка участников не выводить.

## Реализация

- `frontend/src/pages/Profile.js`, блок «Семья» в карточке:
  - удалено описательное `<p className="muted">`;
  - `<span class="family-code">` заменён на `<button>` (клик = копирование);
  - `.copy-btn` — иконка-кнопка с inline SVG (копирование) и aria-label;
  - блок «Участники (N)» + список рендерятся только при members.length > 1;
  - кнопка «Выйти из семьи» — только при members.length > 1;
  - форма «Код приглашения» + «Выйти из семьи» свёрнуты в одну строку
    (.family-actions-row).
- `frontend/src/styles.css`:
  - `.family-code` — размер больше, цвет #24a647, без дефолтных стилей кнопки;
  - `.copy-btn` — белый фон, зелёная иконка, компактный квадрат-«иконка».
  - `.family-actions-row` — flex в одну строку.
- Инлайн SVG вместо сторонней библиотеки иконок (зависимости не добавляем).

## Проверка

- `npm run check` — сборка.

- Ручной сценарий — ниже (заполняется после браузерной проверки).

## Ручной сценарий (требуется выполнить в браузере)

1. Профиль с семьёй, где один участник (я): в блоке «Семья» видна строка
   «Код приглашения: ABCDEF12», код крупный зелёный, рядом белая кнопка-
   иконка. Раздела «Участники» и кнопки «Выйти из семьи» нет.
2. Описания про автосоздание семьи нет.
3. Клик по коду (или по иконке копирования) — код скопирован в буфер обмена.
4. Профиль с семьёй, где несколько участников: список «Участники (N)»,
   кнопки «Присоединиться к семье» и «Выйти из семьи» в одной строке.
5. Проверка клавиатурой: код — фокус, Enter/Escape копируют; иконка
   доступна через Tab.
