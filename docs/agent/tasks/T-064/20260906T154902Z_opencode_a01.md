# T-064: Замена фиолетового цвета кнопок на зелёный

Дата: 2026-09-06T15:49:02Z
Владелец: opencode
Попытка: a01

## Цель

Найти все фиолетовые кнопки на страницах приложения (включая кнопку
«Зарегистрироваться/войти» и подобные) и заменить их цвет на зелёный:

- основной цвет: `#24A647`
- цвет при наведении: `#1A8A39`

Не изменять дизайн, компоненты или логику сайта — только цвет кнопок.

## Анализ

Основное приложение — React SPA в `frontend/`. Все кнопки окрашены в
индиго/сине-фиолетовый `#5b5bea` с hover `#4a4ad4`.

Селекторы кнопок с фиолетовым цветом в `frontend/src/styles.css`:

| Селектор | Строка | background | hover |
|---|---|---|---|
| `button[type="submit"]` | 98-112 | `#5b5bea` (101) | `#4a4ad4` (111) |
| `.copy-btn` | 319-332 | `#5b5bea` (321) | `#4a4ad4` (331) |
| `.upload-btn` | 417-435 | `#5b5bea` (419) | `#4a4ad4` (429) |
| `.btn` | 548-563 | `#5b5bea` (551) | `#4a4ad4` (562) |
| `.period-toggle-btn.active` | 848-851 | `#5b5bea` (849) | — |
| `.landing-btn` (кнопка «Зарегистрироваться/войти») | 982-999 | `#5b5bea` (987) | `#4a4ad4` (998) |

Остальные вхождения `#5b5bea` в `styles.css` относятся к НЕ-кнопкам
(границы фокуса инпутов, ссылки, иконки, прогресс-бары, палитры диаграмм
и т.п.) — по условию задачи их не трогаем.

Отдельный статический Mobirise-шаблон `C:\Dev\index.html` не входит в
git-репозиторий `fin-balance`; его кнопка `btn-primary` (`#229ed9`) не
фиолетовая, поэтому вне области задачи.

## Изменения

`frontend/src/styles.css`:
- `button[type="submit"]` background `#5b5bea` → `#24A647`, hover `#4a4ad4` → `#1A8A39`
- `.copy-btn` background `#5b5bea` → `#24A647`, hover `#4a4ad4` → `#1A8A39`
- `.upload-btn` background `#5b5bea` → `#24A647`, hover `#4a4ad4` → `#1A8A39`
- `.btn` background `#5b5bea` → `#24A647`, hover `#4a4ad4` → `#1A8A39`
- `.period-toggle-btn.active` background `#5b5bea` → `#24A647`
- `.landing-btn` background `#5b5bea` → `#24A647`, hover `#4a4ad4` → `#1A8A39`

## Проверка

- `npm run check` — `Compiled successfully`, бандл
  `build/static/css/main.17434ec4.css` содержит `24a647` (зелёный) вместо
  `5b5bea` для кнопок. Оставшийся `5b5bea` в бандле — только цвет диаграммы
  BarChart (inline в JS), не кнопка.
- В `styles.css` цвет кнопок заменён на `#24a647` (строки 101, 321, 419, 551,
  849, 987) и hover `#1a8a39`. Оставшиеся `#5b5bea` (строки 463, 737, 1052,
  1110) относятся к не-кнопкам (`.progress-bar`, `.percent-bar`,
  `.avatar-placeholder`, `.header-avatar`) и по условию задачи не изменены.
- Кнопки в JS используют CSS-классы (`.btn`, `.btn-secondary`, `.btn-danger`,
  `.landing-btn`, `.copy-btn`) — инлайн-цветов кнопок не найдено.
- Ручная проверка в браузере не проводилась (окружение без GUI); сборка
  бандла подтверждает применение цветов.
