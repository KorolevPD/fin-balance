## Задача

В блоке «Семья» на странице профиля добавить кнопку «Выйти из семьи».
По решению пользователя выход выполняется **с забором своих транзакций**:
при выходе операции пользователя переносятся в его новую (автосозданную)
семью, а из старой удаляются.

## Разрешённая область

- `backend/app/routers/families.py`
- `tests/test_families.py`
- `frontend/src/pages/Profile.js`

## Запрещено

- Несвязанные изменения.
- Новые зависимости.
- Изменение моделей/миграций (выход реализуется без изменения схемы).

## Проверяемые критерии

- [ ] Найден эндпоинт `POST /families/{family_id}/leave`.
- [ ] Выход пересоздаёт пользователю семью и переносит его транзакции.
- [ ] Кнопка «Выйти из семьи» есть в блоке «Семья» профиля.
- [ ] Полный `pytest`, `ruff` и `npm run check` зелёные.

## Выполненные действия

- Изучены `families.py`, `Profile.js`, `models.py`, `test_families.py`.
- Уточнена семантика у пользователя: «выйти, забрав свои транзакции».
- Backend: эндпоинт `POST /families/{family_id}/leave` в `families.py`:
  проверка членства (403 при отсутствии), автосоздание новой семьи,
  перенос транзакций пользователя в новую семью, удаление членства,
  при нуле оставшихся участников — удаление старой семьи и её советов.
- Тесты: 3 новых в `tests/test_families.py`
  (перенос транзакций, удаление семьи последнего участника, 403 для чужой).
- Frontend: кнопка «Выйти из семьи» (btn-danger) в карточке «Семья»
  профиля (`Profile.js`), подтверждение через `confirm`, после выхода —
  перезагрузка данных семьи.
