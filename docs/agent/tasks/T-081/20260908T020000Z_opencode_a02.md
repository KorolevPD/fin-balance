## Что произошло

Пока PR #114 (T-081) был открыт, в origin/main смержен PR #112
(T-078-hover-color-green, merge a0791ac). Обе ветки меняли одни и те же файлы,
из-за чего возникли конфликты:

- `frontend/src/pages/Dashboard.js`, `frontend/src/styles.css` — автослияние
  прошло успешно (маркеров конфликтов нет); обе функциональности сохранены:
  * T-081: `height={308}`, `.demo-chart { min-height: 308px }`,
    `.recharts-legend-wrapper { bottom: 0 }`, удалены label/labelLine у Pie;
  * T-078: 25 вхождений `#24a647` (hover-цвета UI).
- `frontend/build/*` — конфликты (rename/delete, modify/delete, rename/rename):
  это генерируемые CRA-артефакты, ручная склейка бессмысленна.

## Разрешение

1. `git checkout --theirs frontend/build` частично не применился (часть файлов
   существовала только в одной из веток).
2. Весь каталог `frontend/build` удалён из индекса и рабочего дерева
   (`git rm -r --ignore-unmatch frontend/build`), конфликтов в нём не осталось
   (`git diff --diff-filter=U` пуст).
3. Выполнена полная пересборка `npm run check` на объединённых исходниках —
   новый согласованный `frontend/build`, собранный из функциональности ОБЕИХ
   веток (T-081 + T-078).
4. `git add -A frontend/build`, затем merge-commit
   «Merge origin/main into feature/T-081-category-chart-height (resolve
   build/ conflicts)».
