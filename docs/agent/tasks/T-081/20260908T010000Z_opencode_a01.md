# T-081: «Траты по категориям» — высота блока +10% и размещение названий категорий по нижнему краю

## Задача пользователя

При выводе названия категории на диаграмме надпись может выходить за рамки
блока «Траты по категориям». Нужно:
1. увеличить высоту блока для обоих дашбордов на 10%;
2. разместить названия категорий по нижнему краю блока, чтобы они не выходили
   за рамки.

## Контекст

- Диаграмма «Траты по категориям» — единственный компонент в
  `frontend/src/pages/Dashboard.js` (блок `.demo-grid`, режимы «семейный» и
  «личный» — один и тот же блок; поэтому правка применяется к обоим «дашбордам»
  сразу).
- Метки категорий рисовались прямо на секторах (`label`/`labelLine` у `Pie`) и
  при длинных названиях выходили за границы блока.
- Высота: `ResponsiveContainer height={280}` и `.demo-chart { min-height: 280px }`.

## Изменения

1. `frontend/src/pages/Dashboard.js`:
   - убраны `label={...}` и `labelLine={...}` у `Pie` — подписи категорий больше
     не выводятся за рамки блока; названия категорий остаются в `Legend`
     (по нижнему краю);
   - удалены ставшие ненужными `chartTotal`, `shareOf`, `shouldLabelCategory`,
     `shouldLabelLine` и импорт `Curve`;
   - высота диаграммы увеличена на 10%: `height={280}` → `height={308}`.
2. `frontend/src/styles.css`:
   - `.demo-chart { min-height: 308px }` (было 280px);
   - `.demo-chart .recharts-legend-wrapper { bottom: 0 }` — легенда (названия
     категорий) закреплена по нижнему краю блока.

## Проверка

- Frontend: `npm run check`, `CI=true npx react-scripts test`.
- Ручной сценарий (браузер): в блоке «Траты по категориям» (оба режима)
  названия категорий не выходят за рамки, подписаны внизу легендой; высота
  блока увеличена (308px вместо 280px).
