## Найденная первопричина

Кнопка «Удалить» в таблице «Банковские выписки» рендерится в последней
безымянной колонке (`<th></th>` и `<td className="actions-cell">`, Dashboard.js).
Правило `.actions-cell { text-align: right; white-space: nowrap; }`
(styles.css) прижимает кнопку к правому краю колонки. Колонка «Операций»
(`.num`, `text-align: right`) находится сразу слева, поэтому кнопка визуально
оказывается вплотную к числу операций, а свободное место «собирается» справа.
Ожидание — кнопка ровно по середине между числом операций и концом окна —
не достигается, поскольку `text-align: right` не распределяет место по обе
стороны кнопки.

## Цель выполнения

Кнопка «Удалить» располагается ровно по центру свободного пространства между
числом операций и правым краем карточки «Банковские выписки».
