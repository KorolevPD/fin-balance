## Цель выполнения

В тултипе графика «Динамика расходов» на дашборде семьи (`Dashboard.js`)
исчезает подпись «amount» — имя серии, которое Recharts показывает
по умолчанию, когда у `<Bar>` не задан `name`. По выбору пользователя подпись
убирается полностью: в тултипе остаются только период и сумма.

## Диагностика (до изменений)

- `frontend/src/pages/Dashboard.js`, строка 538: `<Bar dataKey="amount" fill="#5b5bea" radius={[4, 4, 0, 0]} />` без `name`.
- Recharts `<Tooltip>` (строки 534–537) с `formatter` и `labelFormatter` — стандартное содержимое тултипа показывает имя серии, равное `dataKey` → «amount».
- Подпись «amount» встречается только в тултипе «Динамики расходов`; у круговой диаграммы «Расходы по категориям» используется `nameKey="category"`, поэтому имя серии там — название категории, и задача её не касается.

## Решение

Заменить стандартный инструмент тултипа динамики на кастомный `content`,
который выводит только метку периода (X-ось) и отформатированную сумму —
без строки с именем серии «amount». Стили тултипа (`frontend/src/styles.css`,
класс `.dynamics-tooltip`) повторяют палитру проекта (белый фон, рамка
`#dfe3ee`, радиус 8px, тень `rgb(20 33 61 / 10%)`, цвет текста `#14213d`).
