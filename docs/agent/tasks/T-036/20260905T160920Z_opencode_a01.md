## Цель выполнения
В списках операций («Сумма») отображать знак «+» для пополнений и «−» для
вычетов, а также окрашивать суммы: пополнения — зелёным, вычеты — красным.

Правила определения на основании `Transaction.type`:
- `type == "income"` → пополнение (знак «+», зелёный);
- `type == "expense"` (или отсутствует) → вычет (знак «−», красный).
