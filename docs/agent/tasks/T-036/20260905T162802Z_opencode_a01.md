# T-036 — Перемещение блока «Общая сумма расходов» вверх

- **Дата:** 2026-09-05T16:28:02Z
- **Владелец:** opencode
- **Попытка:** a01
- **Ветка:** `feature/T-036-dashboard-total-sum-top`

## Задача

Переместить блок «Общая сумма расходов» сразу после заголовка «Дашборд: Мои финансы» и перед блоком «Члены семьи». Остальное не менять.

## Анализ

- Блок «Общая сумма расходов» находится в `frontend/src/pages/Dashboard.js` внутри `section.summary-cards` и рендерится только при наличии данных (`hasData`), после сетки блоков `demo-grid`.
- Заголовок «Дашборд: …» формируется как `Дашборд: ${familyName}` (для семьи «Мои финансы» будет «Дашборд: Мои финансы»).
- Блок «Члены семьи» — первый в `demo-grid`.
- В `DemoDashboard.js` блока «Общая сумма расходов» нет, поэтому правка касается только `Dashboard.js`.

## Изменение

В `frontend/src/pages/Dashboard.js`:
- блок `section.summary-cards` перенесён из нижней части страницы (внутри ветки `hasData`) наверх — сразу после обработки ошибки и перед `div.demo-grid`;
- сохранено условие показа `hasData`, чтобы поведение при отсутствии данных не менялось;
- из нижней ветки `hasData` блок удалён, остальные блоки и их порядок не изменены.

## Проверка

- `npm run check` — сборка проходит.
- `npm run build` — пересобраны артефакты в `frontend/build/`.
- Ручной сценарий: открыть реальный дашборд семьи с данными → под заголовком «Дашборд: …» сразу отображается карточка «Общая сумма расходов», ниже — блок «Члены семьи», все остальные блоки без изменений. Семья без операций: карточка суммы не показывается, как и раньше.
