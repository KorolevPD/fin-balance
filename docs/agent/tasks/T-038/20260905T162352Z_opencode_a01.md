## Цель выполнения
На дашборде семьи (`Dashboard.js`) операции выводятся по дате — старые сверху.
Поменять порядок по умолчанию так, чтобы первыми шли самые новые операции
(дата по убыванию), и дать пользователю возможность сортировать список нажатием
на заголовок колонки «Категория».

Уточнения владельца:
- порядок по умолчанию — «Сначала новые (дата ↓)»;
- сортировка по категории — только на дашборде семьи.

2. `Dashboard.js`: добавлены состояния `sortBy` («date» по умолчанию) и
   `sortDir` («desc» по умолчанию). Функция `handleSort(key)` переключает
   сортировку: повторный клик меняет направление, первый клик задаёт разумное
   направление для колонки. `sortedTransactions` через `useMemo` сортирует

     когда категория не задана.
3. `Dashboard.js`: заголовки таблицы «Дата» и «Категория» стали кликабельными
   кнопками с индикатором направления (▲/▼) и `aria-sort`. Тело таблицы
   рендерит `sortedTransactions`.
4. `styles.css`: добавлен класс `.sort-btn` (наследует стили `th`, hover-цвет
   `#5b5bea`).
