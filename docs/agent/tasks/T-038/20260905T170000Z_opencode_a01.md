# T-038: Переместить блок «Общая сумма расходов» вверх

- **Владелец:** основной агент
- **Дата:** 2026-09-05T17:00:00Z
- **Попытка:** a01

## Цель

Переместить блок «Общая сумма расходов» сразу после заголовка «Дашборд: Мои финансы»
и перед блоком «Члены семьи». Остальное не менять.

## Контекст

Файл: `frontend/src/pages/Dashboard.js`.
Сейчас блок «Общая сумма расходов» находится внутри блока `summary-cards` (строки 218–225)
внутри ветки `hasData`, т.е. после блока «Члены семьи» (строки 118–141).

Требуется: блок «Общая сумма расходов» должен отображаться сразу после `<h1>`
и перед `<section aria-label="Члены семьи">`, независимо от наличия данных.

## Решение

1. Перенести `<section className="summary-cards">` с блоком «Общая сумма расходов»
   из ветки `hasData` вверх — сразу после `<h1>` (и после проверки ошибок/загрузки? —
   решено: сразу после `<h1>`, внутри условной отрисовки по `loading`, чтобы не ломать
   структуру).
2. Остальное содержимое дашборда не менять.

## Проверка

- `npm run check` — Compiled successfully.
- Визуально блок «Общая сумма расходов» отображается первым, перед «Члены семьи».
