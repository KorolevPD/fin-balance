## Задача (переделка a02)

Фон рабочих страниц переделывается под жёсткие геометрические требования:

- Левый край, сверху вниз: `#0b6ad6`, `#008d8f`, `#2fb401`.
- Правый край, сверху вниз: `#01f4b4`, `#c9f11e`, `#fbff00`.
- Цвета распределяются ПО ВЫСОТЕ края, а не от края к центру.
- Каждая сторона занимает ~25 % площади фона, стороны равны по размеру.
- НЕ допускается «расширение градиента кверху»: горизонтальная ширина цветной
  полосы одинакова на любой высоте (сверху не шире, чем снизу).
- Центр остаётся преимущественно чисто белым.
- Мягко, без полос/резких переходов. Только фон рабочих страниц. Публичные
  страницы и весь дизайн/логика — без изменений.

## Почему не один radial на сторону

Один `radial-gradient` на сторону не может одновременно:
(1) давать монотонную смену трёх цветов по высоте края (для этого центр обязан быть
смещён от середины вертикали) и
(2) иметь одинаковую горизонтальную ширину полосы на любой высоте.
Смещённый вверх центр всегда даёт «расширение кверху» (сверху полоса шире, чем
снизу), что прямо запрещено ТЗ.

## Решение: колонна из трёх мягких радиальных слоёв на сторону

Для каждой стороны используется наложение ТРЁХ эллиптических `radial-gradient`
(синий/бирюзовый/зелёный слева; мятный/лайм/жёлтый справа) с одинаковыми
полуосями, сдвинутых по вертикали (центры 20 % / 50 % / 80 % высоты):

- `rx = 30 %` ширины, `ry = 42 %` высоты; прозрачность гасится стопами
  `62% → 50% → 20% → 0%` при 0/25/55/85 радиальной доли `f = sqrt((x/rx)²+((y-yc)/ry)²)`.
- Так как форма затухания по горизонтали у всех трёх слоёв одинакова, результирующая
  интенсивность цветной полосы на ДАННОЙ высоте одинакова сверху и снизу (ширина
  полосы ~22–25 % на любой высоте) — «расширения кверху» нет.
- Вертикально интенсивности трёх слоёв плавно перекрещиваются: у верха доминирует
  первый цвет, в середине — второй, у низа — третий; наложения мягкие, без полос.
- Слева и справа геометрия зеркальна → площади равны.
- Левая колонна размещается в `.dashboard::before`, правая — в `.dashboard::after`
  (два независимых radial-«слоя»/группы, по-прежнему без единого linear-gradient и
  без картинок). Под слоями каждой колонны — базовый `#ffffff`.
