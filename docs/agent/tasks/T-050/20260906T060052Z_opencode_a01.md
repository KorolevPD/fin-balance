## Задача

Добавить на все рабочие (авторизованные) страницы приложения единый адаптивный фон:
мягкий сине-голубой градиент слева и зелёно-жёлто-зелёный справа, с большим чисто-белым
центром. Фон НЕ добавляется на главную страницу, страницы входа и регистрации.

## Анализ структуры

1. Общий layout авторизованной части — `frontend/src/components/Layout.js`, рендерит
   `<div className="dashboard">` и используется единственным местом для авторизованных
   маршрутов в `frontend/src/App.js`.
2. Рабочие страницы (обёрнуты `<PrivateRoute><Layout>`):
   - `/dashboard` → DemoDashboard
   - `/profile` → Profile
   - `/family/:id/dashboard` → Dashboard
   - `/family/:id/operations` → Operations
3. Публичные страницы (без Layout и `.dashboard`): `/` → Landing (`.landing`),
   `/login` → Login (`.auth-form`), `/register` → Register (`.auth-form`).

Вывод: правильный уровень централизации — класс `.dashboard` в `frontend/src/styles.css`.
Публичные страницы не рендерят `.dashboard`, поэтому фон туда не попадёт.

## Выполненные действия

- В `frontend/src/styles.css` к `.dashboard` добавлены `position: relative` и
  `isolation: isolate`, создающие локальный stacking context.
- Добавлен псевдоэлемент `.dashboard::before`:
  - `position: fixed; inset: 0` — занимает весь viewport, не создаёт overflow,
    остаётся на месте при прокрутке (решение `background-attachment: fixed` не
    использовано из-за проблем на iOS и перерисовок при скролле);
  - `z-index: -1` + `isolation: isolate` — фон позади всего UI, под белым шапкой и
    контентом; `pointer-events: none` — не перехватывает клики;
  - фон: `linear-gradient(to right)`, `linear-gradient(to left)` и базовый `#ffffff`
    → синий (#6cb8f0) → голубой (#9fd7f6) → чистый белый центр слева; зелёный
    (#4fbf72) → жёлто-зелёный (#b9d97e) → чистый белый центр справа. Стоп «15%» и
    «30%» дают большой белый участок в центре (30–70 % ширины) и плавное затухание
    без резких границ.
- Добавлен `@media (max-width: 768px)`: прозрачные rgba-варианты с пониженной
  насыщенностью (60 %/28 %/прозрачный), чтобы на планшете и мобильном цвета не
  занимали большую часть экрана и сохранялся белый центр.
- Проверено: класс `<div className="dashboard">` рендерится только в
  `components/Layout.js`; в `App.js` `Layout` оборачивает ровно 4 авторизованных
  маршрута (`/dashboard`, `/profile`, `/family/:id/dashboard`,
  `/family/:id/operations`). Landing, Login, Register не рендерят `.dashboard` →
  новый фон на них не попадает.
- Пересобрана статика: `npm run check` → Compiled successfully, новый CSS
  `main.4eec68ec.css` (содержит `.dashboard:before` и мобильный `@media`), старый
  хэшированный бандл удалён.
