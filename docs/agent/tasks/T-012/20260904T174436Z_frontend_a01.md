## Ручной сценарий проверки

1. Войти под пользователем → нажать «Моя семья».
2. Создать семью: ввести название → появляется карточка с invite_code.
3. Выйти, зарегистрировать второго пользователя → ввести invite_code из шага 2.
4. Открыть семью → виден список из двух участников.
5. Скопировать invite_code (кнопка «Копировать») → вставка в буфер работает.
