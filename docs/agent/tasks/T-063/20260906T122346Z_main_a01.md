# Задача T-063: Устаревшие советы — обновление при загрузке файла

Владелец: основной агент
Дата: 2026-09-06T12:23:46Z
Статус: IN_PROGRESS

## Проблема

При загрузке нового файла советы не меняются и копятся. Ожидание: как
только загрузился новый файл, ИИ автоматически удаляет старые советы и
готовит новый совет по новым данным.

## Первопричина

Между импортом файла и советами нет связи:
- `Dashboard.js`: после успешной загрузки (`onUploaded={() => loadData()}`)
  советы не очищаются и не перегенерируются.
- `generateAdvice(keepExisting=true)` добавляет совет в конец списка
  (`setAdvices(prev => [...prev, advice])`) — накопление.
- Автогенерация при монтировании — только если список пуст
  (`if (list.length === 0 && user?.has_ai_key)`).
- Бэкенд `create_advice` всегда добавляет `AiAdvice` без удаления старых.

## Минимальное исправление

- Бэкенд (`app/routers/ai.py`): `POST /families/{id}/advices?replace=true`
  удаляет все существующие советы семьи перед созданием нового.
  По умолчанию `replace=False` (обратная совместимость).
- Фронт (`frontend/src/pages/Dashboard.js`):
  - `generateAdvice` вызывает `?replace=true` и заменяет список одним
    советом (`setAdvices([advice])`, `setAdviceIndex(0)`);
  - после успешной загрузки файла, если есть AI-ключ, автоматически
    вызывается `generateAdvice()` (fire-and-forget).
- Тесты: новый тест `test_советы_заменяются_при_replace` в
  `test_ai_advices.py`.

## Файлы изменений

- `backend/app/routers/ai.py` — параметр `replace` в `POST .../advices`;
  при `replace=True` удаляются все советы семьи перед созданием нового.
- `frontend/src/pages/Dashboard.js` — `generateAdvice()` вызывает
  `?replace=true` и заменяет список одним советом; `handleUploaded`
  после загрузки файла автоматически генерирует совет при наличии
  AI-ключа.
- `tests/test_ai_advices.py` — новый тест на `replace=True`.
- `frontend/build/*` — пересборка.

## Побочные эффекты

- Кнопка «Новый совет» заменяет совет вместо накопления.
- Перелистывание ◀/▶ становится нерелевантным (в списке один совет).
- Первая генерация с replace=true удалит ранее накопленные советы.
