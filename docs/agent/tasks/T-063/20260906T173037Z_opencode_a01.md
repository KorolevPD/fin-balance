# T-063: Личный дашборд по умолчанию и скрытие переключателя «В семье / Личные»

Дата: 2026-09-06T17:30:37Z
Владелец: opencode
Ветка: `feature/T-063-personal-dashboard-by-default`

## Цель

1. Дашборд по умолчанию должен отображаться в режиме «Личные».
2. Когда пользователь один в семье ИЛИ у членов семьи нет загруженных
   выписок — выводить «Личный» дашборд и не давать пользователю выбирать
   «В семье / Личные» (переключатель скрыт).

## Уточнение (вопрос пользователю)

- «Нет выписок у других»: скрыть переключатель и показывать «Личные»,
  когда пользователь один в семье ИЛИ ни у кого из других участников нет
  своих операций (у них нет загруженных выписок).
- Личный дашборд = только личные данные (фильтр по user_id), без
  переключателя.

## Реализация

### Backend (`app/services/analytics.py`)

В `get_family_summary` добавить поле `other_members_have_statements: bool`:
истина, если у членов семьи кроме запрашивающего пользователя есть хотя бы
одна транзакция с `source_file` (загруженная выписка). Поле не зависит от
`filter_user_id`. Требуется, чтобы фронт мог надёжно определить режим
«только личные» независимо от текущего scope.

### Frontend (`frontend/src/pages/Dashboard.js`)

- `viewScope` по умолчанию = `'personal'` (вместо `'family'`).
- Вычислить `personalOnly`:
  - `userIsAlone = family_members.length <= 1`;
  - `otherMembersHaveStatements = summary.other_members_have_statements`;
  - `personalOnly = userIsAlone || !otherMembersHaveStatements`;
- `effectiveScope = personalOnly ? 'personal' : viewScope`.
- Запросы summary/transactions используют `user_id` при
  `effectiveScope === 'personal'`.
- Переключатель «В семье / Личные» рендерится только при `!personalOnly`.
