# T-084: индикатор генерации и дружелюбная ошибка в блоке «Совет от AI»

- Дата: 2026-09-08T05:00:00Z
- Владелец: opencode
- Ветка: feature/T-084-advice-loading-indicator (от main)
- Предыдущая попытка: нет

## Задача пользователя

В разделе «Совет от AI»:
1. во время генерации ответа должно отображаться состояние генерации —
   например, переливающиеся (анимированные) строки (skeleton);
2. при ошибке генерации — дружелюбная надпись и просьба попробовать снова.

## Контекст

- Флаг `adviceGenerating` (state, Dashboard.js:132) управляет процессом.
- Сейчас при генерации показывается только текст на кнопках
  «Генерация...»; блок совета пуст (ни одного из «этажей» не выводится).
- При ошибке `generateAdvice` (Dashboard.js:229-245) пишет в `adviceError`
  `err.response?.data?.detail || 'Не удалось получить новый совет'` — текст может
  быть техническим, нет явной просьбы повторить.
- Рендер блока (Dashboard.js:442-523) ветвится: `!hasAiAccess` /
  `advicesLoading` / `adviceError` / `currentAdvice` / else.

## Изменения

### frontend/src/pages/Dashboard.js

- В рендере блока «Совет от AI» добавить ветвление по `adviceGenerating`
  (приоритетнее, чем «Совет ещё не сгенерирован» и чем вывода пустого места
  при первом запросе): пока генерация идёт — показывать skeleton из
  переливающихся строк (`.advice-skeleton`).
- В ветке ошибки (`adviceError`): заменить сырой `err`-текст на дружелюбное
  сообщение с просьбой попробовать снова и кнопкой «Попробовать снова»
  (вызов `generateAdvice`).
- Кнопки «Получить совет»/«Новый совет» оставить (текст «Генерация...» при
  `adviceGenerating`), кнопки навигации отключены при `adviceGenerating` (уже).

### frontend/src/styles.css

- Добавить стили скелетона:
  - `.advice-skeleton` — колонка из 3 линий (`.advice-skeleton-line`) с
    анимированной градиентной «переливкой» (CSS `@keyframes`, background
    linear-gradient сдвиг);
  - `@keyframes advice-shimmer` — движение градиента;
  - класс `.advice-error` для дружелюбной ошибки, если нужно.
