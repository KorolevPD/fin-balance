## Задача пользователя

В блоке «Совет от AI» на дашборде нелогично отображается «Совет 1 из 1»; при
генерации второго совета надпись не меняется и переключение не работает.

Нужно:
1. Если в БД ОДИН совет — надпись «Совет X из Y» не выводить.
2. При генерации и добавлении второго совета надпись появляется, переключение
   между советами работает.
3. По умолчанию показывается самый новый совет.

## Анализ

- Backend уже хорош: `GET /families/{id}/advices` возвращает советы свежими
  сверху (`created_at desc, id desc`); `POST` без `replace` создаёт новый совет
  и НЕ удаляет старые.
- Проблема во фронтенде `frontend/src/pages/Dashboard.js::generateAdvice`:
  - запрос уходит с `{ params: { replace: true } }` → сервер удаляет все
    старые советы → всегда остаётся ровно один → «1 из 1» и нечего листать;
  - `setAdvices([advice])` заменяет список вместо добавления.
- Надпись «Совет {n} из {m}» выводится безусловно (`span.advice-counter`) даже
  при `advices.length === 1`.

## Изменения (frontend/src/pages/Dashboard.js)

- `generateAdvice`:
  - убрать `replace: true`;
  - `setAdvices((prev) => [advice, ...prev])` — новый совет в начало;
  - `setAdviceIndex(0)` — сразу показываем самый новый.
- Надпись «Совет X из Y» — только при `advices.length > 1`
  (обернуть `advice-counter` в условие).
- `loadAdvices` уже ставит `setAdviceIndex(0)`, а список приходит свежим
  сверху — по умолчанию новый совет. Менять не требуется.

Backend не меняется.

## Проверка

- Backend не затрагивается; прогнать весь `pytest`, чтобы подтвердить отсутствие
  регрессий, + `ruff`.
- Frontend: `npm run check`, `CI=true npx react-scripts test`.
- Ручной сценарий (браузер): один совет → надписи нет; после генерации второго
  — «Совет 1 из 2», стрелки листают, по умолчанию новый совет.

### Ручной сценарий (браузер, для проверки пользователем)

- В БД один совет: надпись «Совет 1 из 1» НЕ выводится, стрелок нет смысла
  листать.
- Нажать «Новый совет»: создаётся второй совет, надпись «Совет 1 из 2»
  появляется, стрелки листают между советами; по умолчанию показан самый
  новый.
- После перезагрузки страницы со списком советов показывается самый свежий.
- Фактический запуск браузера из CLI невозможен — требуется ручная проверка.

  нового совета в конец массива).
