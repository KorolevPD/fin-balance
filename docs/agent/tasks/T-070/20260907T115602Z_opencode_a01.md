## Выполненные действия

- **docker-compose.yml**: у base-сервисов `backend` и `nginx` убран
  host-маппинг портов (`8000:8000`, `8080:80`) и bind-mount `./backend:/app`;
  backend переведён на `expose: ["8000"]`, команда без `--reload`. Причина:
  в Docker Compose пустые `ports: []`/`volumes: []` из prod-override НЕ
  отменяют списки из base-файла (сливаются конкатенацией) — в проде
  фактически оставались публичные порты 8000 и 8080.
- **docker-compose.override.yml**: в dev добавлены `8000:8000`, `8080:80`,
  bind-mount `./backend:/app` и `command ... --reload` (локальная разработка);
  локальный конфиг nginx без HTTPS сохранён.
- **docker-compose.prod.yml**: удалены неэффективные `ports: []`/`volumes: []`
  и лишний блок `backend`; осталась публикация nginx на 80/443 и монтирование
  `/etc/letsencrypt` + `/var/www/certbot`.
- **deploy.sh**: добавлен детект root для certbot — при не-root пользователе
  выпуск/продление выполняются через `sudo` (иначе certbot не может писать
  в `/etc/letsencrypt` и забиндить порт 80).
- **nginx/Dockerfile**: `npm install` → `npm ci` (детерминированная сборка).
- **.github/workflows/ci.yml**: job `js-tests` переведён в `frontend`
  (working-directory), `npm ci` вместо `npm install`, параметр
  `cache-dependency-path`, команда `npm test -- --watchAll=false` + сборка
  `npm run check`; добавлен job `python-tests` (`pytest -q tests`);
  в линт добавлен каталог `tests`.
- **frontend/src/categories.test.js**: новый минимальный тест (без DOM),
  чтобы `npm test` в CI проходил (раньше CI падал: ни тестов, ни package.json
  в корне).
- **ruff**: исправлены W292 (конец файла) в `backend/app/database.py` и
  `backend/alembic/env.py`, E501 в `backend/app/models/models.py`;
  в `pyproject.toml` добавлен exclude автогенерируемых `backend/alembic/versions`.
- **deploy/DEPLOY.md**: уточнён список шагов CI и использование `sudo`
  для certbot на сервере.
