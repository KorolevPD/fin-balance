# T-070 — Кнопки навигации по AI-советам (шевроны)

**Владелец:** основной агент
**Дата:** 2026-09-07T13:44:01Z
**Статус:** IN_PROGRESS

## Цель

Заменить текстовые кнопки переключения советов («◀», «▶») в блоке «Совет от AI»
на дашборде двумя минималистичными кнопками-шевронами по требованиям PRODUCT.md
и описания задачи.

## Требования задачи

- Левая кнопка — крупный шеврон «<» строго влево, из двух толстых прямых
  диагональных линий одинаковой толщины, соединённых в одной внутренней точке;
  концы сильно закруглены; форма аккуратная, гладкая, симметричная.
- Правая кнопка — точная горизонтально симметричная копия «>» (тот же размер,
  толщина линий, пропорции, степень закругления).
- Цвет стрелок — однородный нейтральный светло-серый примерно `#BDBDBD`.
- Плоский, чистый, современный UI на белом фоне. Без градиентов, обводок,
  теней, свечения, текстур, прозрачности, 3D, кругов/прямоугольных фонов.
- Стрелки должны занимать столько же места, сколько предыдущие кнопки.

## Анализ

В `frontend/src/pages/Dashboard.js` блок «Совет от AI» (строки 422–498) содержит
`.advice-controls` с тремя кнопками: `◀`, «Новый совет», `▶`. Задача — заменить
две навигационные кнопки (`◀`/`▶`) на SVG-шевроны. Кнопка «Новый совет»
(генерация нового совета) не является кнопкой переключения и остаётся.

Стиль `.advice-controls` в `styles.css` (1000–1006) — flex с gap 8px.

## План

1. Создать SVG-компонент (инлайн) шеврона или две кнопки с inline SVG.
2. Заменить `◀` и `▶` в `Dashboard.js` на кнопки с SVG-шевронами, оставив
   атрибуты `disabled`, `aria-label`, `onClick`.
3. Добавить CSS-класс `.advice-nav-btn` и стили для стрелок (#BDBDBD, закруглённые
   концы линии, без фона/обводки/теней, тот же размер кнопок).
4. Проверить: `npm run check`.

## Проверка

- `npm run check` — Compiled successfully (main.27717820.js, main.f9d3cead.css).
- Визуально: две серые стрелки-шеврона на белом фоне, занимают прежнее место.

## Итог

Левая и правая навигационные кнопки заменены на SVG-шевроны. Обе используют
`stroke="#BDBDBD"`, `strokeWidth=3`, `strokeLinecap/Linejoin=round` — полная
горизонтальная симметрия. Кнопка «Новый совет» (генерация) не является
навигационной и сохранена. `.advice-nav-btn` задаёт прозрачный фон без обводки,
рамки, теней, градиентов и прозрачности стрелки.
