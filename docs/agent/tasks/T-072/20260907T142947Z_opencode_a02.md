4. Выравнивание: верхняя граница логотипа = верхняя граница заголовка; нижняя граница логотипа = нижняя граница последнего абзаца. Логотип не растягивается выше высоты текстового блока.

## Изменения

### frontend/src/styles.css

- `.landing-content`:
  - `display: grid` → `display: flex` (row).
  - Соотношение колонок: `.landing-text { flex: 1 1 65%; }`, `.landing-logo { flex: 0 0 35%; }`.
  - `align-items: stretch` — колонки одной высоты по общей оси.
  - `min-width: 0` на текстовом блоке, чтобы текст не выходил за колонку.
- `.landing-text`: `flex: 1 1 65%`, `min-width: 0`.
- `.landing-logo`: `flex: 0 1 35%`, выравнивание по высоте текста (`align-self: stretch`).
- `.landing-logo img`: `max-height: 100%; max-width: 100%; height: 100%; width: auto; object-fit: contain` — логотип занимает высоту текстового блока (равна верхней границе заголовка сверху и нижней границе последнего абзаца снизу), но не растягивается больше.
- Текст крупнее: `.landing-title` → `2.5rem`, `.landing-description` → `1.15rem`, `.landing-note` → `1.05rem`; `line-height` увеличен (1.2 → 1.35 у заголовка; 1.5 → 1.7 у абзацев).
- `overflow-wrap: break-word` для абзацев — текст не вылезает за колонку.
- `.landing-auth-link a`: `color: #24a647` (зелёный).
- Медиа-запрос 720px: `flex-direction: column`, логотип на всю ширину.
