# T-072 — Стартовая страница: двухколоночный макет (Flexbox) и зелёное слово «Войти»

## Предыдущие попытки

Нет (новая задача).

## Цель

Изменить композицию элементов на карточке стартовой страницы (Landing.js / styles.css).

1. Сделать двухколоночный макет на Flexbox: слева увеличенный текстовый блок (заголовок и 2 абзаца), справа логотип `logo1.png`.
2. Выровнять блоки по одной горизонтальной оси.
3. Кнопку «Зарегистрироваться» и текст «Уже есть аккаунт? Войти» оставить на месте. Кнопку не менять.
4. Слово «Войти» перекрасить в зелёный.

## Текущее состояние (до изменений)

- `frontend/src/pages/Landing.js` — карточка `.landing-window` с `.landing-content`: заголовок + 2 абзаца слева, логотип `/logo1.png` справа, ниже кнопка и ссылка.
- `frontend/src/styles.css`:
  - `.landing-content` — уже две колонки, но через `display: grid` (`grid-template-columns: 1fr 1fr`).
  - `.landing-logo` — `.landing-logo img { max-width: 100% }`.
  - `.landing-auth-link a` — цвет `#5b5bea` (фиолетовый), жирный, без подчёркивания.
  - медиа-запрос на 720px переводит сетку в одну колонку.

## Изменения

### frontend/src/styles.css

- `.landing-content`: `display: grid` → `display: flex`; `flex-direction: row`; убрать фиксированные `grid-template-columns`, оставить `gap` и `align-items: center` (общая горизонтальная ось). Текстовый блок растягивается через `flex: 1 1 auto`.
- Добавлен класс `.landing-text` (или задан `flex: 1`): увеличенный текстовый блок слева.
- `.landing-logo`: `flex: 0 0 auto`, чтобы логотип занимал вторую колонку справа.
- `.landing-auth-link a`: цвет → зелёный (зелёный тон как кнопки `#24a647`).
- Медиа-запрос 720px: `.landing-content { flex-direction: column; }`.

### frontend/src/pages/Landing.js

- В структуре разметки `.landing-content` уже есть `.landing-text` и `.landing-logo` — менять не требуется (только если нужен класс-обёртка для flex:1 — он уже есть: `.landing-text`).
