## Задача пользователя

1. Поменять интеграцию AI-ассистента с Gemini на GigaChat.
2. Убрать все другие интеграции (Gemini, OpenAI-совместимые) — только GigaChat.
3. В профиле предлагать пользователю загрузить только данные для интеграции с
   GigaChat, если нет глобального API-ключа в env. Если ключ есть в env — раздел
   «AI-ассистент» в профиле не выводится вовсе.
4. Если GigaChat API-ключ есть в env, на дашборде должна быть возможность
   получить совет от AI (сейчас выводится «Добавьте бесплатный AI-ключ в профиле...»).
5. Переименовать .env-переменные, связанные с ИИ-функционалом.

## Решения пользователя (уточнены в чате)

- `GEMINI_API_KEY` → `GIGACHAT_API_KEY`.
- `AI_KEY_ENCRYPTION_KEY` оставить как есть (нейтральное имя, не привязано к провайдеру).
- Поле в профиле принимает **Authorization Key** GigaChat; бэкенд по нему получает
  временный access-токен (OAuth, 30 мин) и вызывает `chat/completions`.

## Особенности GigaChat API (по официальной документации, авг-окт 2026)

- Токен доступа: `POST https://ngw.devices.sberbank.ru:9443/api/v2/oauth`,
  form: `scope=GIGACHAT_API_PERS`, заголовки: `RqUID: <uuid4>`,
  `Authorization: Basic|Bearer <ключ_авторизации>`. Ответ: `{"access_token": ...}`.
- Генерация: `POST https://api.giga.chat/v1/chat/completions` (OpenAI-формат),
  заголовок `Authorization: Bearer <access_token>`, тело `{"model": "GigaChat",
  "messages": [...]}`, `stream: false`.
- Модель по умолчанию: `GigaChat`.
- Документация не рекомендует передавать `temperature`/`top_p` — опускаем их.
