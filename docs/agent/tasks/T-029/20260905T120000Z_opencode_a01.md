# T-029: Примерный дашборд с моковыми данными

**Владелец:** opencode
**Дата:** 2026-09-05T12:00:00Z
**Попытка:** a01

## Задача

Создать примерный дашборд приложения без реальных данных с 4-блочным макетом:
- Строка 1, 1/3: Таблица членов семьи с суммарными тратами (сортировка по тратам)
- Строка 1, 2/3: Круговая диаграмма распределения трат по категориям
- Строка 2, 2/3: Загруженные файлы с периодом (дата первой/последней операции) и количеством операций
- Строка 2, 1/3: Пустой блок (заглушка для будущего)

## Реализация

### Бэкенд

- `backend/app/routers/demo.py` — эндпоинт `GET /api/demo/dashboard` с моковыми данными:
  - `family_members` (имя, суммарные траты, отсортированы по убыванию)
  - `categories` (категория, сумма)
  - `uploaded_files` (имя файла, период начала/конца, количество операций)
- `backend/main.py` — регистрация роутера `demo`.

### Фронтенд

- `frontend/src/pages/DemoDashboard.js` — новый компонент:
  - CSS Grid `1fr 2fr` (колонки 1/3 и 2/3), 2 строки
  - Блок 1: таблица членов семьи
  - Блок 2: круговая диаграмма (recharts PieChart)
  - Блок 3: пустая заглушка «Резерв»
  - Блок 4: таблица загруженных файлов с периодом и количеством операций
  - адаптив: на ширине ≤ 900px сетка в одну колонку
- `frontend/src/styles.css` — стили `.demo-grid`, `.demo-block`, `.demo-block-empty`, `.demo-chart`
- `frontend/src/App.js` — маршрут `/dashboard` теперь рендерит `DemoDashboard` вместо `DashboardStub`.
