## Ситуация

PR #125 (`feature/T-091-mobile-responsive`, мобильный адаптив) стал
несливаемым: GitHub показал `mergeable: CONFLICTING`, потому что в `main`
после создания моего PR влили другую фичу с тем же идентификатором задачи —
`feature/T-091-advice-scope-invalidation` (PR #124, «AI-советы разделены по
scope»). Обе ветки меняют одни и те же файлы фронтенда
(`frontend/src/pages/Dashboard.js`, `components/UploadModal.js`,
`TransactionEditModal.js`) — отсюда конфликты.

Замечание: идентификатор `T-091` оказался занят двумя разными ветками
(советы по scope и мобильный адаптив). Это коллизия именования задач в
`TASKS.md`; в рамках данной итерации сохранён мой каталог
`docs/agent/tasks/T-091/`, где лежат оба timestamp-файла (a01 — адаптив,
a02 — эта запись), а файл `20260907T220700Z_opencode_a01.md` относится к
другой ветке это фичи main.

## Конфликты

`git merge origin/main` показал конфликты только в **генерируемых
build-артефактах**:

- `frontend/build/asset-manifest.json`;
- `frontend/build/index.html`;
- `frontend/build/static/js/main.*.js` (+ `.LICENSE.txt`, `.js.map`) —
  rename/rename конфликт: моя сборка `main.5d885506.js` и сборка main
  `main.5647db98.js` обе переименованы из `main.8233ff31.js`.

Исходники (`Dashboard.js`, `UploadModal.js`, `TransactionEditModal.js`,
`styles.css`) смёржились автоматически без конфликтов.

## Решение

1. Для конфликтных build-артефактов применён стандартный для проекта
   подход «пересборка»: удалён весь каталог `frontend/build/` из индекса и
   рабочей копии, затем выполнен `npm run build` по смёрженным исходникам.
2. Проверено, что в итоговом коде присутствуют обе функциональности:
   - мой мобильный адаптив в `frontend/src/styles.css`
     (`@media (max-width: 720px)`, `.table-scroll .data-table { min-width:
     620px }`, `-webkit-overflow-scrolling: touch` и др.) и обёртки
     `.table-scroll` в `Dashboard.js`;
   - `advice_scope` из main (`TransactionEditModal.js:42`,
     `UploadModal.js:99`).
3. Проверка отстМаркеров конфликта в `frontend/src/` и `backend/app/`
   нет (`grep` не находит `<<<<<<<`/`=======`/`>>>>>>>`).
4. Merge закоммичен: `7b69f03`.
