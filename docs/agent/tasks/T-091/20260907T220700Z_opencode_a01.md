## Задача пользователя

1. AI-советы генерируются и хранятся отдельно для дашбордов «Личные» и
   «Семейный» (scope: `personal` / `family`).
2. При любом изменении операций (группы/личной) все советы группы и
   пользователя удаляются (стали неактуальны) и сразу генерируется новый
   совет для активного режима.

## Решения (утверждены пользователем)

- «Новый совет сразу» генерирует **бэкенд в фоне** (BackgroundTasks) после
  синхронного удаления устаревших советов.
- Хранение: поле `scope` в `AiAdvice`. После изменения операций генерируется
  **один** совет для активного режима (`advice_scope` от фронтенда, по
  умолчанию `personal`). Семейные советы общие для семьи, личные — только
  для владельца.

## Ручной сценарий проверки интерфейса (docs/rules/frontend.md)

1. Новой семьёй без операций: режим «Личные» — блок «Совет от AI» пустой,
   кнопка «Получить совет» генерирует совет для личного режима (секрет семьи
   в сводке).
2. Переключение режима «Семейный»: список советов пуст, генерируется совет
   по общей сводке. Вернуться в «Личные» — личный совет на месте.
3. Загрузка выписки (режим «Личные»): операция появляется, совет автоматически
   обновляется на новый (в фоне), его текст учитывает добавленную операцию.
4. Правка категории операции: совет автоматически обновляется (в фоне).
5. Удаление выписки: операции пропадают, совет автоматически обновляется.
6. Повторная загрузка той же выписки (дубли): совет не меняется (нет
   инвалидации).
7. Член семьи в режиме «Личные» видит только свои личные советы; в «Семейном» —
   общие советы семьи.
