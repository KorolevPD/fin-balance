# T-046 Попытка a01 — График не должен обновляться при сортировке «Расходы по категориям»

Владелец: opencode
Дата: 2026-09-06T07:35:53Z
Статус: IN_PROGRESS
Ветка: feature/T-046-chart-independent-of-sort

## Задача

При сортировке данных в окне «Расходы по категориям» на дашборде график расходов
в начале страницы постоянно обновляется (перерисовывается). Нужно убрать обновление
графика и его зависимость от сортировки в окне «Расходы по категориим».

## Причина

В `frontend/src/pages/Dashboard.js`:

- `categories` — это `useMemo`, зависящий от `summary`, `catSortBy`, `catSortDir`, `total`
  и возвращающий **отсортированный** список категорий (сортировка определяется полями
  таблицы «Расходы по категориям»).
- `chartCategories` вычисляется каждый рендер как `categories.filter(...)`.

Клик по заголовку таблицы меняет `catSortBy`/`catSortDir` → пересоздаются `categories`
с новым порядком элементов → `chartCategories` меняет свой порядок и `PieChart`
в начале страницы перерисовывается.

## Решение

Вынести построение списка категорий (добавление «Прочее», если его нет) в отдельный
`useMemo` `categoryList`, зависящий ТОЛЬКО от `summary`. Тогда:

- `categories` получает из `categoryList` и сортирует его по `catSortBy`/`catSortDir` — для таблицы;
- `chartCategories` получает из `categoryList` и фильтрует — для графика, не зависит от сортировки.

Набор элементов и их суммы графика не меняются при сортировке, поэтому `PieChart`
перестанет перерисовываться.

## Проверка

- `npm run check` — Compiled successfully (main.74e594b6.js).
- Ручная проверка логики: `chartCategories` теперь строится из `categoryList`
  (зависит только от `summary`), а не из отсортированного `categories`. Изменение
  `catSortBy`/`catSortDir` меняет только порядок строк таблицы, но не состав,
  порядок и суммы фрагментов графика → `PieChart` не перерисовывается.
- Ручная проверка в браузере запланирована как обязательный шаг перед мержем
  (правила frontend.md), но перерисовку устраняет изменение зависимости мемо.
