## Задача

Пользователь заметил: при нажатии «Дашборд» в шапке открывается только
«Примерный дашборд» (`DemoDashboard`) без реальных данных, хотя после импорта
выписки во вкладке «Загрузить» реальные данные по дашборду есть (по адресу
`/family/{id}/dashboard`, компонент `Dashboard`).

Требуемая логика:
- если у пользователя есть операции — при переходе на `/dashboard` показывать
  реальный дашборд;
- если операций нет — показывать «Примерный дашборд».

## Анализ

- `frontend/src/App.js` — маршрут `/dashboard` рендерит `DemoDashboard`;
  реальный дашборд — `/family/:id/dashboard` (компонент `Dashboard`).
- `Layout.js` — ссылка «Дашборд» и логотип ведут на `/dashboard`.
- `DemoDashboard.js` — всегда запрашивает `/demo/dashboard` и показывает примерные
  данные.
- Есть API `GET /families/my` → список семей; `GET /families/{id}/summary` →
  сводка с ключами `total_amount`, `by_category`, `uploaded_files`.

## Решение (frontend, без изменения backend)

В `DemoDashboard.js` при загрузке:
1. Запросить `/families/my`.
2. Для каждой семьи запросить `/families/{id}/summary`.
3. Если `total_amount > 0` или есть `by_category`/`uploaded_files` — редирект
   (`<Navigate>`) на реальный дашборд `/family/{id}/dashboard` первой такой семьи.
4. Если операций нет ни в одной семье — показать «Примерный дашборд», как раньше.

## Проверка

- `npm run check` — Compiled successfully.
- Ручной сценарий: без операций → «Примерный дашборд»; после импорта во вкладке
  «Загрузить» → переход по «Дашборд» в шапке открывает реальные данные.
