# Задача T-059: Изначально показывать только расходы (кнопка «Убрать пополнения»)

Владелец: основной агент
Дата: 2026-09-06T10:05:17Z
Статус: IN_PROGRESS

## Проблема

После загрузки файла на дашборде и на странице «Все операции» изначально
показываются и расходы, и пополнения. По ожиданию должны показываться только
расходы, а кнопка «Убрать пополнения» так же показывает/скрывает их.

## Первопричина

Начальное значение состояния `hideIncomes` установлено в `false`.
При `false` мемоизированный `visibleTransactions` возвращает **все**
транзакции без фильтрации (`if (!hideIncomes) return transactions`),
поэтому пополнения видны сразу.

## Признаки в коде

- `frontend/src/pages/Dashboard.js:118` — `useState(false)`.
- `frontend/src/pages/Operations.js:34` — `useState(false)`.
- `Dashboard.js:140-143`: `visibleTransactions` при `!hideIncomes` возвращает
  все транзакции без фильтра `type !== 'income'`.

## Минимальное исправление

Поменять `useState(false)` → `useState(true)` в двух файлах:
- `frontend/src/pages/Dashboard.js:118`
- `frontend/src/pages/Operations.js:34`

Серверная логика не затрагивается.

## Проверка

- `npm run check` — Compiled successfully.

## Поверка воспроизведения

1. Вход, загрузка CSV с пополнениями и расходами.
2. Дашборд → в списке «Операции» только расходы (красные, `−`).
3. «Показать пополнения» → появляются пополнения (`+`, зелёные),
   кнопка меняется на «Убрать пополнения».
4. «Убрать пополнения» → пополнения исчезают.
5. Страница «Все операции» — те же шаги.
