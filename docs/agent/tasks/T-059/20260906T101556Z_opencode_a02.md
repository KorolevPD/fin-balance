- styles.css в ветке не менялся (bran change не содержит) → не конфликтует.

## Решение

3. Пересобрать `npm run check` из смерженного исходника — build перепишется
   целиком, сохранив фичу ветки (`hideIncomes=true`) и изменения main (T-060).
4. Коммит-merge с двумя родителями → `origin/main` предок ветки.
5. Push + проверка `gh pr view 68` → mergeable=CLEAN.
