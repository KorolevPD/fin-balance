## Цель выполнения

На диаграмме «Траты по категориям» подписи категорий накладываются друг на друга.
Нужно, чтобы категории, занимающие менее одного процента общей суммы диаграммы,
не подписывались.

## Диагностика (до изменений)

- `frontend/src/pages/Dashboard.js`, строки 288–318: секция «Траты по категориям»
  (`PieChart`/`Pie` из recharts) с `label={(entry) => entry.category}` — подпись
  рисуется для каждой категории `chartCategories` (любая сумма > 0), включая мелкие
  сегменты, текст которых накладывается.
- `frontend/src/pages/DemoDashboard.js`, строки 135–162: та же диаграмма по
  данным `categories` с `label={(entry) => entry.category}` — та же проблема
  для демо-макета.
- Общая сумма на диаграмме вычисляется как сумма модулей amount показываемых
  сегментов.

## Решение

В обоих компонентах добавить вычисление общей суммы сегментов и функцию-подпись,
которая возвращает название категории, если её доля >= 1 % общей суммы, иначе
`null` (recharts не рисует подпись при `null`):

- `Dashboard.js`: сумма по `chartCategories`, `label={shouldLabelCategory}`.
- `DemoDashboard.js`: сумма по `categories`, та же функция.
