# T-059 Попытка a02 — Скрыть линии labelLine у категорий < 1%

Владелец: opencode

Статус: IN_PROGRESS
Ветка: feature/T-059-chart-label-threshold

## Задача

После скрытия подписей категорий < 1 % линии-указатели (labelLine) recharts
продолжают рисоваться до пустого места. По решению заказчика: убрать линии
у категорий < 1 %, у подписанных категорий (>= 1 %) линии остаются.

## Диагностика

- В recharts (es6/polar/Pie.js, строка 137) label и labelLine рисуются независимо:
  `labelLine && Pie.renderLabelLineItem(labelLine, lineProps, 'line')`. Значит
  `label` с порогом не скрывает линию.
- `labelLine` принимает функцию: `renderLabelLineItem` при isFunction вызывает
  `option(props)` и использует результат (React-элемент или null).
- Для линии нужен элемент `Curve` — он экспортируется из recharts
  (`export { Curve }`).

## Решение

Вынести общий помощник доли категории `shareOf(entry)`, переиспользовать его в
`shouldLabelCategory` (label) и новой `shouldLabelLine` (labelLine):

- `shouldLabelLine = (props) => shareOf(props) >= 1 ? <Curve type="linear" {...props} className="recharts-pie-label-line" /> : null`
- передать `labelLine={shouldLabelLine}` рядом с `label={shouldLabelCategory}`.

Применить в `Dashboard.js` и `DemoDashboard.js`.
