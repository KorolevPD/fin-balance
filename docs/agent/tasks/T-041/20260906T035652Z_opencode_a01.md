## Ручной сценарий проверки в браузере

1. Пользователь без данных заходит на /dashboard (после входа).
   Ожидается: «Примерный дашборд», в разделе «Загруженные файлы» кнопка
   «Загрузить».
2. Клик «Загрузить» → открывается модальное окно «Загрузка выписки».
   В заголовке/оверлее кнопки «Загрузить» и «Дашборд» отсутствуют;
   навигация слева — логотип, справа — имя/аватар и «Выйти».
3. Выбрать файл examples/sber.csv (или произвольный CSV) и нажать «Загрузить».
   Ожидается: прогресс, затем «✓ Готово» и сообщение о количестве операций.
4. Авторедирект на реальный дашборд /family/{id}/dashboard при загрузке с
   /dashboard, где виден файл в «Загруженных файлах» и операции.
5. На реальном дашборде в разделе «Загруженные файлы» кнопка «Загрузить»
   открывает модалку; повторная загрузка того же файла после «Загрузить ещё»
   работает (дубли пропущены).
6. Закрытие модалки: Esc / клик по оверлею / «Отмена». Во время загрузки
   закрытие невозможно.
7. Клавиатура: выбранный файл доступен через Tab; Enter по кнопке «Загрузить»
   запускает импорт.
