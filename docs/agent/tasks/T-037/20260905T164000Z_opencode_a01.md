# T-037 Попытка a01 — Завершение состояния загрузки: «Готово» и повторная загрузка

Владелец: opencode
Дата: 2026-09-05T16:40:00Z
Статус: IN_PROGRESS

## Описание проблемы
После успешной загрузки файла прогресс застревает на «Загрузка... 100%»,
кнопка «Загружается...» остаётся заблокированной навсегда, выбрать новый
файл невозможно.

## Первопричина
- `setProgress(100)` в `handleUpload` (Upload.js:134) не сбрасывается —
  нет завершающего состояния «Готово».
- Кнопка `disabled={!file || !familyId || progress !== null}` (Upload.js:196/276)
  заблокирована, пока `progress !== null`, т.е. вечно после загрузки.
- `<input type="file">` не сбрасывает `value` — повторный выбор того же файла
  не вызывает событие `change`.

## План исправления (минимальное)
1. Флаг `done` (`useState(false)`).
2. Успех в `handleUpload` → `setDone(true)`; новый файл в `handleFile` → `setDone(false)`.
3. Прогресс-блок (обе ветки рендера): при `done` — `✓ Готово` зелёным,
   иначе прежний «Загрузка... X%».
4. Кнопка: `disabled={!file || !familyId || (progress !== null && !done)}`;
   текст `done ? 'Загрузите файл' : ...`; клик в состоянии `done` открывает
   выбор файла (клик по input).
5. Сброс `value` input после успеха для повторного выбора того же файла.
6. CSS: `.upload-progress.done` / `.progress-label.done` — зелёный.

## Изменённые файлы
- frontend/src/pages/Upload.js
- frontend/src/styles.css

## Что сделано
1. Добавлен флаг `done` (`useState(false)`).
2. `handleUpload`: успех → `setDone(true)` + сброс `value` input файла;
   ошибка/создание семьи → `setDone(false)`.
3. `handleFile` (выбор нового файла) и `reset` сбрасывают `done`.
4. Обе ветки рендера формы: при `done` шкала показывает `✓ Готово`
   зелёным, иначе прежний «Загрузка... X%».
5. Кнопка: `disabled={!file || !familyId || (progress !== null && !done)}`,
   текст `done ? 'Загрузите файл' : ...`; клик в состоянии `done` открывает
   выбор файла (`handleBtnClick` → клик по input `csvFile`).
6. CSS: `.upload-progress.done`, `.upload-progress.done .progress-bar`,
   `.progress-label.done` — зелёная палитра (#16a34a/#15803d/#dcfce7).
