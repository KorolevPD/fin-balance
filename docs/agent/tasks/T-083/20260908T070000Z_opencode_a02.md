## Разрешение

1. `git rm -rf frontend/build` — весь каталог удалён из индекса и рабочего
   дерева; `git diff --diff-filter=U` пуст (конфликтов нет).
2. Полная пересборка `npm run check` на объединённых исходниках — новый
   согласованный `frontend/build` с функциональностью ОБЕИХ веток.
3. `git add -A frontend/build`, затем merge-commit
   «Merge origin/main into feature/T-083-personal-advice-first-row (resolve
   build/ conflicts)».
