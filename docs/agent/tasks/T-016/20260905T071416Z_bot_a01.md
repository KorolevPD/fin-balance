## Блокеры и риски

- Локально доступен только Python 3.14; проект и CI нацелены на Python 3.11. Точечные версии зависимостей (aiogram 3.3.0 → pydantic v1, aiohttp 3.9.1, pydantic 2.5.2) не собираются на 3.14, поэтому bot-хэндлеры проверены только компиляцией (`py_compile`) и соответствием существующим паттернам aiogram 3.x. В CI (3.11) зависимости устанавливаются штатно.
- `tests/test_upload_backend.py` не запускается локально из-за несовместимости версий starlette/httpx (предсуществующая проблема окружения, не связана с изменениями T-016).
- Полная проверка привязки требует реального Telegram-токена и запущенного backend; покрыта unit-тестами структуры и роутов.
