# T-065: Отступ между кнопками «Присоединиться к семье» и «Выйти из семьи»

Дата: 2026-09-06T16:32:04Z
Владелец: opencode
Попытка: a01

## Цель

Сделать отступ между кнопками «Присоединиться к семье» и «Выйти из семьи»
равным отступу между полем ввода кода приглашения и кнопкой
«Присоединиться к семье».

## Анализ

Блок «Семья» находится в `frontend/src/pages/Profile.js` (строки 400-426):

- `<form onSubmit={handleJoin}>`
  - `.form-group` — поле «Код приглашения»; `.form-group` имеет
    `margin-bottom: 16px` (styles.css, строка 52)
  - `<button type="submit" className="btn">` — «Присоединиться к семье»
- `<div className="profile-actions">` — кнопка `btn-danger` «Выйти из семьи»

Отступ между полем ввода и кнопкой «Присоединиться» = `16px`
(`margin-bottom` `.form-group`).

Отступ между кнопкой «Присоединиться» и «Выйти из семьи» = `0px`, т.к.
`.profile-actions` (styles.css, строки 1068-1073) не имеет верхнего отступа.

`.profile-actions` используется в двух местах Profile.js:
- строка 344 — AI-карточка (внутри формы), там верхний отступ уже обеспечен
  соседним `.form-group`;
- строка 417 — блок «Семья» (после `</form>`), отступа нет.

Чтобы не изменить отступы в AI-карточке, отступ добавляем точечно для
контейнера кнопки «Выйти из семьи».

## Изменения

1. `frontend/src/pages/Profile.js`:
   - блоку `.profile-actions` на строке 417 добавить класс `family-actions`:
     `className="profile-actions family-actions"`.
2. `frontend/src/styles.css`:
   - после `.profile-actions` добавить правило
     `.family-actions { margin-top: 16px; }` — тот же отступ, что и
     `margin-bottom` `.form-group`.

## Проверка

- `npm run check` — `Compiled successfully`.
- Профиль: в блоке «Семья» отступ между кнопками «Присоединиться к семье»
  и «Выйти из семьи» стал `16px` (`.family-actions { margin-top: 16px }`),
  такой же как отступ между полем ввода и кнопкой «Присоединиться к семье»
  (`.form-group { margin-bottom: 16px }`).
- Другие `.profile-actions` (AI-карточка, строка 344) не затронуты —
  там класс `family-actions` не добавлен.
