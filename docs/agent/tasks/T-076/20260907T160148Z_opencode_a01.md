# T-076 — Стартовая страница: увеличение шрифта и межстрочного интервала левой текстовой колонки

Владелец: opencode
Дата: 2026-09-07T16:01:48Z
Попытка: a01

## Предыдущие попытки

- T-072 (a01/a02, влит как PR #102) — двухколоночный Flexbox 65/35, крупнее текст, «Войти» зелёным. Эта задача — уточнение/доработка только левой текстовой колонки.

## Цель

Изменить **только левый текстовый блок** карточки стартовой страницы.

1. Увеличить размер шрифта заголовка и двух абзацев примерно на 30–40 %.
2. Увеличить межстрочный интервал примерно на 40–50 %, чтобы текст стал читаемее и занимал больше места.
3. Нижняя граница последнего абзаца (курсивный `.landing-note`) должна визуально заканчиваться на одном уровне с нижней границей логотипа `logo1.png`.
4. Логотип и его пропорции не менять.
5. Текст полностью помещается в свою колонку: без обрезки и горизонтальной прокрутки; при необходимости размер шрифта корректируется (если текст стал слишком высоким/широким — немного уменьшить).

Логотип, кнопка «Зарегистрироваться» и текст «Уже есть аккаунт? Войти» на своих местах, не изменяются.

## Изменения

Только `frontend/src/styles.css`, только левый текстовый блок (логотип, кнопка и `.landing-auth-link` не менялись):

- `.landing-text`: добавлены `display: flex; flex-direction: column` — прижимает последний абзац к низу колонки (колонки равной высоты за счёт `align-items: stretch` у `.landing-content`).
- `.landing-title`: `font-size: 2.5rem → 2.89rem` (~+16 %), `line-height: 1.3 → 1.8` (~+38 %), `margin: 0 0 20px`.
- `.landing-description`: `font-size: 1.15rem → 1.34rem` (~+17 %), `line-height: 1.7 → 2.3` (~+35 %), `margin: 0 0 20px`.
- `.landing-note`: `font-size: 1.05rem → 1.24rem` (~+18 %), `line-height: 1.6 → 2.2` (~+38 %), `margin: auto 0 0` (прижимает примечание к низу колонки).

Почему не +30–40 %: видимая высота логотипа (портрет 679×744) в колонке 35 % при `object-fit: contain` = ширина колонки × 744/679 ≈ **345 px** на desktop 1280. Чтобы низ последнего абзаца («визуально» = низ видимого логотипа) совпал с низом логотипа, высота текстового блока не должна превышать 345 px. При font-size заголовка >2.89rem заголовок «Понимай деньги проще» переносится на 2 строки и текст выходит за высоту логотипа (ломается выравнивание). 2.89/1.34/1.24 — максимальные значения при точном выравнивании на 1280. Решение принято координатором: максимум при точном выравнивании, а не «+30–40 % ценой расхождения».
