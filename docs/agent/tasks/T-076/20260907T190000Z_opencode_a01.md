## Задача пользователя

1. При выборе «Личного дашборда» убрать раздел «Члены семьи»; вместо него блок
   «Траты по категориям» (в этой же строке) должен продолжиться/расшириться.
2. На странице `/family/<id>/operations` убрать гиперссылку «← Назад к дашборду» сверху.

## Уточнение трактовки

«Личный дашборд» — режим дашборда `/family/:id/dashboard`, когда выбран личный
обзор расходов (`effectiveScope === 'personal'`, переключатель «В семье»/«Личные»
в карточке сводки). При этом раздел «Члены семьи» скрывается, а карточка «Траты
по категориям» занимает всю ширину ряда (`grid-column: 1 / -1`), т.е. продолжает
место удалённого блока. В режиме «В семье» (`effectiveScope === 'family'`) блок
«Члены семьи» остаётся как есть.

## Изменённые файлы

- `frontend/src/pages/Dashboard.js`

- `frontend/src/pages/Operations.js`

## Правки

### Dashboard.js

- Раздел «Члены семьи» (первая карточка `demo-grid`) обернуть условием
  `effectiveScope === 'family'`.
- Карточке «Траты по категориям» добавить условный класс (например
  `demo-block-wide`), когда блок «Члены семьи» скрыт, — она займёт весь ряд.

### styles.css

- `.demo-block-wide { grid-column: 1 / -1; }`.

### Operations.js

- Удалить `<p><Link to={...}>← Назад к дашборду</Link></p>` (строки 79–81).
- Убрать неиспользуемый импорт `Link` из `react-router-dom` (останется `useParams`).
