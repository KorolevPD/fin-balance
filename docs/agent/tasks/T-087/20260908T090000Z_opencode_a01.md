# T-087 (a01): подключение favicon набора в React-приложение

- Дата: 2026-09-08T09:00:00Z
- Владелец: opencode
- Ветка: feature/T-087-add-favicons
- Задача: добавить предоставленный favicon-набор в проект, затем удалить
  `favicon.zip` из корня (чтобы архив не попал в репозиторий).

## Что лежало в favicon.zip

- favicon.svg, favicon.ico, favicon-96x96.png, apple-touch-icon.png,
  web-app-manifest-192x192.png, web-app-manifest-512x512.png, site.webmanifest.

## Изменения

- `frontend/public/` — распакованы 6 графических файлов +
  `site.webmanifest`.
- `frontend/public/site.webmanifest` — name/short_name заменены с
  «MyWebSite»/«MySite» на «FinBalance»; theme_color = фирменный #24a647.
- `frontend/public/index.html` — подключены: favicon.ico (sizes=any),
  favicon.svg (svg+xml), apple-touch-icon, manifest, theme-color.
- `frontend/build/*` — пересборка CRA перенесёт public-файлы в сборку.

## Проверка

- `npm run check` — Compiled successfully.
- После сборки в `frontend/build/` присутствуют favicon.ico, favicon.svg,
  apple-touch-icon.png, иконки web-app-manifest и обновлённый index.html
  со ссылками на них.

## Удаление архива

- `rm favicon.zip` — файл untracked (git status `?? favicon.zip`), удалён
  до коммитов, чтобы не попасть в репозиторий.
