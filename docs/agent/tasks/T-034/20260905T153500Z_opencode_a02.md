## Описание проблемы
Пользователь не может загрузить файл, не состоя в семейной группе. Frontend
полностью скрывает форму загрузки при `families.length === 0`.

## План исправления
1. Убрать ранний `return` в Upload.js (строки 126-139), всегда показывать форму.
2. В `handleUpload`: если семей нет — автосоздать «Мои финансы» через `POST /api/families`.
3. Обновить стейт families/familyId после автосоздания.

## Изменённые файлы
- frontend/src/pages/Upload.js

## Что сделано
1. Убран ранний `return` при `families.length === 0` (бывшие строки 126-139).
   Теперь вместо заглушки «Нужна семья» показывается форма загрузки с
   выбором файла и пояснением про автосоздание семьи «Мои финансы».
2. В `handleUpload` добавлено автосоздание семьи через `POST /api/families`
   имени «Мои финансы», если у пользователя ещё нет семей. После создания
   импорт выполняется в новую семью.

## Ручная проверка
Ожидаемый сценарий:
1. Зарегистрировать нового пользователя (без семьи).
2. Перейти на `/upload` — форма загрузки видна сразу.
3. Выбрать CSV/PDF — кнопка «Загрузить» активна.
4. После нажатия автоматически создаётся семья «Мои финансы», файл
   импортируется, операции появляются в списке.

## Побочные эффекты
- У пользователя может появиться автоматическая семья «Мои финансы» —
  это необходимо, т.к. `Transaction.family_id` NOT NULL.
- Риск низкий: срабатывает только при отсутствии семей.
