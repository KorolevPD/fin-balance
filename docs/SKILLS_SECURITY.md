# Безопасное использование Agent Skills

## Skill — это не только инструкция

Skill может включать:

```text
skill-name/
├── SKILL.md        инструкции и метаданные
├── scripts/        исполняемый код и shell-скрипты
├── references/     справочные материалы
├── assets/         шаблоны и дополнительные файлы
└── другие ресурсы
```

Поэтому сторонний skill следует оценивать как стороннюю программу или зависимость, которую вы собираетесь запустить на своём компьютере.

## Что потенциально может сделать исполняемый код

В зависимости от разрешений он может:

- читать и изменять файлы проекта;
- запускать команды;
- устанавливать пакеты;
- обращаться в интернет;
- читать переменные окружения;
- получить доступ к токенам и API-ключам;
- изменить Git-репозиторий;
- удалить файлы;
- отправить содержимое проекта внешнему сервису.

## Проверка перед установкой

- [ ] Известен источник и автор.
- [ ] Есть открытый исходный код.
- [ ] Понятна лицензия.
- [ ] Просмотрен `SKILL.md`.
- [ ] Просмотрены `scripts/` и другие исполняемые файлы.
- [ ] Понятны все shell-команды.
- [ ] Проверены сетевые запросы.
- [ ] Проверен доступ к файлам и переменным окружения.
- [ ] Skill не требует `sudo` без объективной причины.
- [ ] Skill не дублирует уже установленный инструмент.
- [ ] Первый запуск можно провести в тестовом репозитории или контейнере.

## Красные флаги

```bash
curl ... | bash
wget ... | sh
sudo ...
rm -rf ...
chmod +x ...
printenv
cat ~/.ssh/*
git push --force
```

Отдельные команды могут быть легитимны, но они всегда требуют понимания и подтверждения.

## Как искать skills

Можно попросить чат-модель найти и сравнить существующие skills в интернете, но нельзя доверять выдуманным ссылкам. Требуйте реальный репозиторий, дату обновления, лицензию, список scripts и анализ разрешений. Ничего не устанавливайте автоматически по одному только описанию.

## Правило проекта

Подключайте новый skill только тогда, когда можете назвать повторяющуюся задачу, которую он решает. Для небольшого хакатона обычно достаточно нескольких непересекающихся skills, а не коллекции «на все случаи жизни».
