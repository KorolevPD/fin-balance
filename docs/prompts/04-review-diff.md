# Промпт: проверить изменения

Для независимого review по возможности используйте модель другого производителя, чем модель-исполнитель.

```text
Проверь только текущие незакоммиченные изменения.
Сравни их с PRODUCT.md, PLAN.md и текущей записью в TASKS.md.

Сначала ничего не исправляй. Пиши отчёт на русском языке.

Проверь:
1. Соответствие требованиям и этапу PLAN.md.
2. Лишние изменения вне области задачи.
3. Ошибки обработки пустых и граничных значений.
4. Возможную потерю данных.
5. Слишком сложные решения.
6. Отсутствующие проверки.
7. Риски безопасности.

Перечисли проблемы по критичности и укажи конкретные файлы и строки.
После отчёта предложи только минимальные исправления.
```
