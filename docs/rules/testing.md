# Правила тестирования

Читайте этот документ только при создании или изменении тестов.

1. Сформулируйте наблюдаемое поведение.
2. Для ошибки сначала создайте воспроизводящий тест.
3. Убедитесь, что тест падает по правильной причине.
4. Внесите минимальное исправление.
5. Запустите целевой тест.
6. Запустите весь набор тестов.
7. Запишите результат в карточке задачи.

Не отмечайте задачу завершённой, если проверка не была запущена или её результат неизвестен.
