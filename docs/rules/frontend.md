# Правила интерфейса

Читайте этот документ только при работе с пользовательским интерфейсом.

- Основной пользовательский сценарий должен работать с клавиатуры.
- Для полей ввода используйте связанные `label`.
- Для кнопок используйте понятные русские подписи.
- Не передавайте смысл только цветом.
- Проверяйте пустые значения, длинный текст и повторное действие.
- Не добавляйте визуальные эффекты, если они мешают завершить MVP.
- После изменения интерфейса запишите короткий ручной сценарий проверки в карточке задачи.
