# Правила безопасности

Читайте этот документ при работе с сетью, ключами, зависимостями, skills или MCP.

- Не храните секреты в Git.
- Не вставляйте реальные ключи в промпты.
- Проверяйте домен и источник загружаемого кода.
- Не разрешайте агенту доступ ко всему домашнему каталогу без необходимости.
- Перед установкой пакета или skill просматривайте команды и зависимости.
- Новые MCP-серверы подключайте отключёнными и включайте только после проверки.
- Не отправляйте наружу файлы проекта без явного согласия команды.
- При сомнении остановитесь и запросите подтверждение человека.
