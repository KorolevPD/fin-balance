# Промпт: проверить PLAN.md и создать TASKS.md

```text
Изучи AGENTS.md, PRODUCT.md, черновой PLAN.md, структуру репозитория и текущий git status.

Пока не изменяй исходный код. Все документы и пояснения пиши на русском языке.

1. Проверь, соответствует ли PLAN.md фактическому репозиторию.
2. Исправь в PLAN.md только необходимые архитектурные, зависимостные и тестовые детали.
3. Создай TASKS.md — конкретные задачи по 30–60 минут:
   - технические детали реализации;
   - владелец, статус и разрешённые файлы;
   - проверяемые критерии и прогресс выполнено/всего;
   - блокер;
   - последний файл выполнения;
   - точный следующий шаг.
4. Для каждой задачи укажи, как она связана с этапом PLAN.md.

Перед каждой попыткой выполнения создавай новый файл:
docs/agent/tasks/T-XXX/YYYYMMDDTHHMMSSZ_<OWNER>_aNN.md

Не отмечай функциональность выполненной без запуска или теста.
Не дублируй текущий прогресс в PLAN.md.
Не добавляй функции, которых нет в PRODUCT.md.
```
