# Промпт: продолжить после перезапуска

```text
Продолжи выполнение сохранённого плана проекта.

Сначала ничего не изменяй. Все документы, статусы и пояснения пиши на русском языке.

1. Прочитай AGENTS.md, PRODUCT.md, PLAN.md и TASKS.md.
2. Найди текущую задачу IN_PROGRESS.
3. Открой последний файл выполнения, указанный в TASKS.md.
4. Проверь git status, git diff и последние commits.
5. Сравни сохранённое состояние с фактическими файлами и результатами тестов.
6. Кратко сообщи: что завершено, что осталось и какой следующий шаг.
7. Создай новый файл:
   docs/agent/tasks/T-XXX/YYYYMMDDTHHMMSSZ_<OWNER>_aNN.md
8. Добавь ссылку на предыдущую попытку и продолжи с поля «Точный следующий шаг».

Не создавай новый PLAN.md, если стратегия реализации и тестирования не изменилась.
Не переделывай задачи DONE, если их проверки продолжают проходить.
Во время работы обновляй только новый timestamp-файл. После проверки координатор обновляет TASKS.md.
```
